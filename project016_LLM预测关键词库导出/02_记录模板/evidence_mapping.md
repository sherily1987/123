# evidence.mapped 字段枚举与映射参考（UNFITTED）

> 本表全部内容为 **UNFITTED 参考起点**，不是已校准参数。只有事实证据明确时才映射，且必须带来源/采集时间/依据；未回测系数不得假装精确。

## 1. mapped 合法值（evidence[] 必填字段）

| 类别 | 取值 | 含义 |
| --- | --- | --- |
| 进攻缺阵 | `attack_absence_home` / `attack_absence_away` | 锋线/核心攻击手伤停或停赛 |
| 后防缺阵 | `defense_absence_home` / `defense_absence_away` | 主力后卫伤停 |
| 门将缺阵 | `gk_absence_home` / `gk_absence_away` | 主力门将无法出战 |
| 轮换 | `rotation_home` / `rotation_away` | 杯赛轮换/密集赛程轮换 |
| 战意 | `attack_motive_home` / `attack_motive_away` | 必须抢攻（保级/争冠/次回合落后） |
| 压上风险 | `defense_risk_home` / `defense_risk_away` | 抢攻带来的后防暴露 |
| 近况/主客 | `form_context` / `home_adv` / `venue` | 状态、主场优势、场地（人工草皮等） |
| 历史交锋 | `h2h_background` | 仅低权重背景，不用胜负频率当概率 |
| 赛事背景 | `cup_context` | 赛制/晋级路径/双回合背景 |
| 客队策略 | `away_strategy` | 客场求稳/对攻等战术信号 |

## 2. 战意五级（事实→映射参考）

| 等级 | 证据 | 方向性修正参考 | 备注 |
| --- | --- | --- | --- |
| 保级战（濒临降级区，剩余<5场） | 积分榜位置 + 剩余赛程 | `attack_motive` 上调（上限 1.35 内） | 必须核实是否已无保级可能 |
| 争冠/争四战 | 积分差距 < 3 分 | `attack_motive` 上调 | 主客场强度差异计入 home_adv |
| 已无欲求 | 排名区间 + 理论积分上限 | 不作上修 | 轮换风险 → `rotation_*` |
| 杯赛轮换 | 官方发布会/首发预测 | `rotation_*` 0.2–0.5 | 双回合次回合落后方 attack_motive |
| 德比/宿敌 | 赛程性质 | 仅叙事，不默认改概率 | 需真实攻防数据佐证 |

**铁律**：战意必须来自可引用证据，禁止"看起来没欲望"式臆测。

## 3. 赔率走势复核线索（体彩官方 observed_at 时间线）

| 走势信号 | 参考解读 | 动作 |
| --- | --- | --- |
| 主胜赔率 开盘→即期 下降 >0.10 | 市场资金/信息驱动 | 不直接改概率；记录 odds_movement，与模型对照 |
| 主胜赔率 上升 >0.15 | 背离 | 检查伤停/轮换新闻；无新闻视为噪声 |
| 平局赔率 跌破 3.00 | 平局可能性上升（3504 场经验：≤3.00 档实际平局 33.3%） | 若模型平局概率 <25% 提示检查 |
| 让球盘线变化 | HHAD line 变盘 | 复核是否伴随 HAD 同向移动 |

**约束**：走势只作复核线索，不是独立概率输入；最终概率仍由量化引擎产生。

## 4. 已证伪做法（禁止复活）

- ❌ "战意40% + 赔率35% + 历史25%" 固定加权合成胜率
- ❌ 热门队天然降权（低赔≠爆冷，低赔代表高隐含概率）
- ❌ "赔率<1.5 必爆冷"
- ❌ 用历史交锋胜负频率直接当下一场概率（H2H 仅低权重背景）
- ❌ 单轮命中率证明模型有效（评价看长期 Brier/LogLoss/ECE/CLV）
