# 工作区测试入口

工作区是多个独立项目的集合，不能从根目录直接用一次 `pytest` 收集全部文件：同名模块和各项目的本地导入约定会相互污染。

运行方式：

```powershell
python .\project020_工作区测试入口\02_脚本\run_workspace_tests.py
```

入口会分别进入每个项目的工作目录运行测试。`required: true` 的失败使命令退出为非零；归档导出副本会完整记录为 `ARCHIVED_FAILURE`，不被写成“通过”，也不阻断当前工作区的有效测试门禁。

可加 `--report <路径>` 写入完整 JSON 证据报告。
