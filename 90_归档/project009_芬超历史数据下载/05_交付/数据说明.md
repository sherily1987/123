# 芬超（Veikkausliiga）数据说明

## 1. 数据内容

- 来源：API-Football v3（`/fixtures?league=244&season=Y`），免费计划
- 赛季：2022、2023、2024（免费版开放上限）
- 场次：505 场（2022 年 167、2023 年 169、2024 年 169，含冠军组/降级组与附加赛）
- 状态：501 场 FT、3 场 PEN、1 场 AET，全部带比分

## 2. 文件

| 文件 | 说明 |
| --- | --- |
| `04_素材/apifootball_raw/veikkausliiga_2022/2023/2024.json` | API 原始信封 |
| `04_素材/标准化/veikkausliiga_results_2022_2024.csv` | 统一建模格式 |

CSV 字段与韩职/挪超一致：`competition, season_end_year, date, home, away,
home_goals, away_goals, status, source`，可直接合并建模。

## 3. 刷新方法

```powershell
python 02_脚本\fetch_veikkausliiga_apifootball.py            # 默认 2022-2024
python 02_脚本\fetch_veikkausliiga_apifootball.py --delay 0  # 已拉过时快速重合并
```

免费版赛季范围变化或升级后，修改 `SEASONS` 重跑即可（幂等、断点续传）。

## 4. 口径提醒

- 本数据为赛果/比分，供强度与比分建模；竞彩回测仍须走体彩官方赔率登记链。
- 芬超是夏季联赛（4–10 月），与北欧其他联赛同季，可作为交叉验证样本。
