# 小白 Codex 安装图文教程 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `project001_小白Codex安装图文教程` 内交付可直接发布的 7 页小红书教程文案、7 张竖版示意配图和发布检查清单。

**Architecture:** 文案与发布说明以 Markdown 分文件保存；每一张配图为独立的 1080 x 1440 PNG，采用白底大字步骤卡并配合非官方 UI 的中性示意。交付清单把图片顺序、官方截图替换点、账号权限提醒与发布前检查集中在一处。

**Tech Stack:** Markdown、Image Generation、PowerShell 文件检查。

## Global Constraints

- 所有文件必须位于 `H:\claude AI自媒体\project001_小白Codex安装图文教程`。
- 受众为没有编程基础的 Windows 新手；使用短句、朋友式语气，不使用 CLI、API Key、终端或插件安装说明。
- 每页只讲一个动作，标题 10–18 字，步骤不超过 3 条。
- 图片为 1080 x 1440 PNG，白底、黑色大字、OpenAI 绿作小面积提示色。
- 不伪造官方界面或下载按钮；第 3、5、6 页必须使用“放官方截图”示意框。
- 不承诺所有 ChatGPT 账号均具备 Codex 权限；引导使用官方渠道。
