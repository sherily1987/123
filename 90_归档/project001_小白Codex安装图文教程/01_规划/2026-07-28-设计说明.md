# 小红书图文教程设计说明

## 目标

制作一套面向 Windows 小白的 7 页小红书图文教程，教用户安装 ChatGPT 桌面版、切换到 Codex、选择本地项目文件夹并发送第一个任务。

## 受众与边界

- 受众：没有编程基础、首次使用 Codex 的 Windows 用户。
- 形式：竖版小红书图文；每页只讲一个动作。
- 口径：采用当前官方产品结构——Windows ChatGPT 桌面版包含 Codex 入口。
- 不包含：CLI、API Key、终端、插件安装，以及未经官方确认的下载链接。

## 页面结构

1. 封面：一句结果导向标题，建立“10 分钟上手”的预期。
2. 准备：Windows 电脑、稳定网络、可登录的 ChatGPT 账号。
3. 下载：从官方 Windows 下载入口获取 ChatGPT 桌面版。
4. 登录：打开应用并使用 ChatGPT 账号登录。
5. 进入 Codex：从左上角切换至 Codex。
6. 选文件夹：创建或选择专用项目文件夹，授权应用访问。
7. 首个任务：提供一条可复制提示词，并以三条避坑提示收尾。

## 文案与视觉规范

- 语气：朋友式、短句、无技术术语。
- 单页正文：标题 10–18 字；步骤不超过 3 条；关键按钮用引号标示。
- 视觉：白底、黑色大字、OpenAI 绿作提示色；每页保留截图/示意图区域。
- 配图：不伪造官方界面和下载按钮；以教程示意图、键盘/Windows 场景或留白截图框为主。

## 交付物

- `02_文案/`：7 页逐页文案、发布正文、标题和标签。
- `03_配图/`：7 张竖版配图（封面与 6 张内页）。
- `05_交付/`：发布顺序与检查清单。

## 验收

- 新手只看图片和文案即可完成安装、登录、进入 Codex、开始首个任务。
- 不引导用户使用非官方渠道；不承诺所有账号都具备相同权限。
- 全部项目文件仅位于 `project001_小白Codex安装图文教程`。
