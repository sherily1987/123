# 小红书图文教程设计说明

## 目标

制作 7 页竖版小红书图文，帮助没有编程基础的 Windows 用户完成：从官方渠道安装 ChatGPT 桌面版、登录、进入 Codex、选择本地项目文件夹并发送第一个任务。

## 受众与边界

- 受众：首次使用 Codex 的 Windows 小白。
- 口径：Windows ChatGPT 桌面版包含 Codex 入口；具体权限依账号、套餐、地区与工作区设置而异。
- 不包含：CLI、API Key、终端、插件安装、未经官方确认的下载链接。
- 每页只传达一个动作；不伪造官方界面或下载按钮。

## 视觉方案 A：白底大字步骤卡

- 尺寸：1080 x 1440 像素，竖版 3:4。
- 版式：顶部大号页标题，中部仅放 1 个教学示意与不超过 3 条步骤，底部放页码或提醒。
- 色彩：白底、近黑文字；OpenAI 绿仅作编号、箭头与重点提示。
- 截图位：第 3、5、6 页提供清晰截图框，并用“放官方截图”标注；发布前替换为用户在官方产品中实际截取的画面。
- 示意：使用键盘、Windows 电脑、文件夹、鼠标等中性元素；不绘制或仿造 ChatGPT 官方 UI。

## 页面内容

1. 封面：10 分钟上手，完成安装到首个任务。
2. 准备：Windows、稳定网络、可登录 ChatGPT 账号。
3. 下载：进入官方 Windows 下载入口并下载桌面版；保留官方截图框。
4. 登录：打开应用，用 ChatGPT 账号登录。
5. 进入 Codex：从左上角选择 Codex；保留官方截图框。
6. 选文件夹：创建或选择专用项目文件夹，授权访问；保留官方截图框。
7. 首个任务：提供可复制提示词，并收尾三条避坑提醒。
