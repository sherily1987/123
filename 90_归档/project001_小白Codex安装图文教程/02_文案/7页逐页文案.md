# 7 页逐页文案

## 01｜封面

**标题：** 10 分钟用上 Codex

**副标题：** Windows 小白从安装到第一个任务

**页面文案：**

1. 安装 ChatGPT 桌面版
2. 进入 Codex
3. 选好文件夹，发出第一句任务

**页脚：** 跟着做就行，不需要编程基础。

## 02｜准备

**标题：** 先准备这 3 样东西

**页面文案：**

1. 一台 Windows 电脑
2. 稳定的网络
3. 能登录的 ChatGPT 账号

**页脚：** 准备好后，下一页开始安装。

## 03｜下载

**标题：** 只从官方渠道下载

**页面文案：**

1. 搜索“ChatGPT 官方下载”
2. 找到 Windows 桌面版
3. 下载后，双击安装文件

**截图位：** 放官方截图：Windows 下载入口或下载完成页。

**页脚：** 不点第三方下载站，安全第一。

## 04｜登录

**标题：** 打开后先登录账号

**页面文案：**

1. 打开刚安装好的应用
2. 点击“登录”
3. 使用你的 ChatGPT 账号完成登录

**页脚：** 登录后，页面会自动进入 ChatGPT。

## 05｜进入 Codex

**标题：** 左上角切换到 Codex

**页面文案：**

1. 看左上角的产品切换位置
2. 找到并选择“Codex”
3. 进入后，新建一个任务

**截图位：** 放官方截图：左上角的 Codex 入口。

**页脚：** 如果看不到 Codex，不代表你操作错了，先检查账号权限与可用地区。

## 06｜选文件夹

**标题：** 给项目选一个专用文件夹

**页面文案：**

1. 新建或选择一个项目文件夹
2. 名字写清楚，例如“我的第一个项目”
3. 按提示授权应用访问

**截图位：** 放官方截图：选择文件夹与授权访问的画面。

**页脚：** 一个项目一个文件夹，资料才不会乱。

## 07｜首个任务

**标题：** 复制这句话，开始吧

**可复制提示词：**

> 我是新手。请先查看这个项目文件夹里的内容，再用简单的话告诉我：这里有什么、我下一步可以做什么。不要修改文件，先给我一个清晰的行动清单。

**避坑提示：**

1. 第一次先让它“查看”，别急着改文件。
2. 一次只说一个目标，结果更清楚。
3. 重要修改前，先让它告诉你会改什么。

**页脚：** 你已经完成第一次 Codex 任务了。
