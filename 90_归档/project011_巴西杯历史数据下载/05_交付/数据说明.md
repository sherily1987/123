# 巴西杯（Copa Do Brasil）数据说明

## 1. 数据内容

- 来源：API-Football v3（`/fixtures?league=73&season=Y`），免费计划
- 赛季：2022、2023、2024（免费版开放上限）
- 场次：366 场（每季 122 场，含资格轮与各轮淘汰赛）
- 状态：346 场 FT、1 场 AET、19 场 PEN（点球决胜），全部带比分

## 2. 文件

| 文件 | 说明 |
| --- | --- |
| `04_素材/apifootball_raw/copa_do_brasil_2022/2023/2024.json` | API 原始信封 |
| `04_素材/标准化/copa_do_brasil_results_2022_2024.csv` | 统一建模格式 |

CSV 字段与韩职/挪超/芬超/瑞超一致：`competition, season_end_year, date, home,
away, home_goals, away_goals, status, source`，可直接合并建模。

## 3. 刷新方法

```powershell
python 02_脚本\fetch_copa_do_brasil_apifootball.py            # 默认 2022-2024
python 02_脚本\fetch_copa_do_brasil_apifootball.py --delay 0  # 已拉过时快速重合并
```

免费版赛季范围变化或升级后，修改 `SEASONS` 重跑即可（幂等、断点续传）。

## 4. 口径提醒

- 本数据为赛果/比分，供强度与比分建模；竞彩回测仍须走体彩官方赔率登记链。
- 杯赛含低级别球队，跨级别实力差大，建模时建议保留轮次信息（raw JSON 中有 round 字段）。
