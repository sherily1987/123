# 挪超（Eliteserien）数据说明

## 1. 数据内容

- 来源：API-Football v3（`/fixtures?league=103&season=Y`），免费计划
- 赛季：2022、2023、2024（免费版开放上限）
- 场次：726 场（每季 242 场 = 30 轮常规赛 + 升降级附加赛）
- 状态：725 场 FT（完赛）、1 场 PEN（点球决胜）；全部带比分

## 2. 文件

| 文件 | 说明 |
| --- | --- |
| `04_素材/apifootball_raw/eliteserien_2022/2023/2024.json` | API 原始信封（含 fixture id、轮次、场馆等） |
| `04_素材/标准化/eliteserien_results_2022_2024.csv` | 统一建模格式 |

CSV 字段：`competition, season_end_year, date, home, away, home_goals, away_goals, status, source`
（与 project004 韩职合并 CSV 字段一致，可直接合并建模）。

## 3. 刷新方法

```powershell
python 02_脚本\fetch_eliteserien_apifootball.py            # 默认 2022-2024
python 02_脚本\fetch_eliteserien_apifootball.py --delay 0  # 已拉过时快速重合并
```

免费版赛季范围变化或升级后，修改脚本内 `SEASONS` 重跑即可（幂等、断点续传）。

## 4. 口径提醒

- 本数据为赛果/比分，供强度与比分建模；竞彩回测仍须走体彩官方赔率登记链。
- 挪超是竞彩常开赛事（北欧联赛），后续可纳入每日流水线积累配对样本。
