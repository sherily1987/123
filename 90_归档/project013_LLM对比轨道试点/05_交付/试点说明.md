# LLM 对比轨道试点说明

## 方法

同场比赛，两条轨道赛前独立预登记：

1. **量化轨道**：fusion_predict（体彩官方盘口 + 校准层），输出概率与比分 Top3；
2. **LLM 轨道**：按关键词库搜索（伤停/阵容/战意/近况/H2H）→ LLM 依据可引用证据
   输出定性方向（可双选）+ 比分偏好 + 风险信号，全部带来源；

赛后回填官方赛果，对比：

- 胜平负：量化 argmax vs LLM 单选/双选是否覆盖实际结果；
- 比分：双方 Top1/Top3 是否命中；
- 回避/风险信号质量（定性记录）。

## 本场试点结论（赛前视角）

- 量化：主胜 41.7%（argmax=主胜）；
- LLM：双选主胜/平局，单选偏好平局——理由：双方大面积伤停、首回合保守、
  巴西杯 H2H 67% 平局、主队主场近 5 次对客队不败但平局居多；
- 两轨方向一致（主胜/平局区间），差异在单选偏好与比分倾向（LLM 更偏小球）。

## 长期化条件

- 每场预登记成本：3–6 次搜索 + 1 次结构化阅读；
- 至少累计 100–200 场后再比较两轨命中率（单场不做结论）；
- 后续可加第三轨：量化 + 证据账本修正（把 LLM 找到的事实经 adjustment_ledger
  注入 fusion_predict，验证证据是否提升量化表现）。
