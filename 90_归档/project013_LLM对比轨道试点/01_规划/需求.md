# 需求

- 项目名称：LLM对比轨道试点（project013）
- 类型：对比研究类项目
- 目标：用一场真实比赛验证「搜索证据 → LLM 结构化判断」能否作为独立对比轨道，
  与量化引擎预测并排预登记、赛后统一回测对比命中率。
- 试点场次：巴西国际 vs 科林蒂安（2026-08-03 06:30，巴西杯八强首回合）
- 验收标准：
  1. LLM 判断在开球前预登记（含来源证据）；
  2. 量化轨道与 LLM 轨道同场并排存档；
  3. 赛后回填赛果后输出两者命中对比。
- 约束：LLM 轨道只输出定性方向/比分偏好，不声明概率（数字只由脚本产生）；
  证据必须带来源 URL 与采集时间。
