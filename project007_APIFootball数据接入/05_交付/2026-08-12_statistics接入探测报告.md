## 2. 响应内容

单场 `statistics` 数组（英超 2024-03-02 Brentford 2-2 Chelsea）：

```
Shots Total        14 : 17      Shots Inside Box    9 : 9
Shots On Goal       5 : 6       Shots Outside Box   5 : 8
Shots Off Goal      7 : 6       Corners             0 : 6
Shots Blocked       2 : 5       Ball Possession   31% : 69%
Attacks            96 : 137     Passes Total      288 : 638
Dangerous Attacks  34 : 44      Saves               3 : 3
```

同时返回 `statistics_1half`（半场统计，30/30 覆盖）、`lineup`、`player_stats`、
`substitutions`、`cards`、`goalscorer`。

### 2.1 一致性校验通过

两组切分互相独立且都等于总数：

- 主队：`14 = 5 + 7 + 2`（on/off/blocked），`14 = 9 + 5`（inside/outside）✓
- 客队：`17 = 6 + 6 + 5`，`17 = 9 + 8` ✓
- 2021 样例：`18 = 4 + 7 + 7`，`18 = 12 + 6` ✓

### 2.2 ⚠️ 解析陷阱：`type` 会重复出现，且重复项是 0

```
Attacks            96 : 137
Attacks             0 : 0        ← 重复项
On Target           5 : 6
On Target           0 : 0        ← 重复项
Throw In            0 : 0
Throw In            0 : 0
```

**用 `{s['type']: s for s in statistics}` 这种字典推导会取到最后一条，也就是 0。**
必须取**首次出现**（或取两者中较大者）。这是本次探测最重要的实现约束，
落地时要有测试守住。
