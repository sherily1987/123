# API-Football v3 接入说明

## 1. 认证与额度

- Base URL：`https://v3.football.api-sports.io`
- 认证：请求头 `x-apisports-key: <key>`；key 从环境变量 `API_FOOTBALL_KEY` 读取，
  已写入用户级环境变量，任何脚本/输出均不落盘。
- 响应信封：`{get, parameters, errors, results, paging, response}`
- 当前账号：Free 计划，100 次/天，10 次/分；有效期至 2027-08-02。
- 免费版赛季限制：**仅开放 2022-2024 赛季**（实测 2025 赛季返回
  `Free plans do not have access to this season`）。
- 免费版限流：**10 次/分钟**（实测连发 18 个请求时第 11 个起被拒）；批量脚本必须限速，
  建议 ≥7 秒/请求，并处理 `errors.rateLimit` 重试。

## 2. 用法

```powershell
python api_football_adapter.py status
python api_football_adapter.py leagues --season 2024 --output leagues.json
python api_football_adapter.py teams --search "Manchester United"
python api_football_adapter.py fixtures --date 2026-08-02 --output fixtures.json
python api_football_adapter.py standings --league 39 --season 2024 --output standings.json
python api_football_adapter.py injuries --league 39 --season 2024 --output injuries.json
python api_football_adapter.py h2h --home 33 --away 34 --output h2h.json
```

子命令：`status` / `leagues` / `teams` / `fixtures` / `standings` / `injuries` / `h2h`。
`--output` 写入完整信封 JSON；stdout 只打印状态与预览（最多 10 条）。

## 5. 口径与边界（重要）

- API-Football 的 `/odds` 是博彩公司赔率（Bet365 等），**不是中国体彩固定奖金**，
  不能替代体彩官方链路，只能做 enrich。
- 免费版只开放 2022-2024 赛季；需要近期/实时赛季请升级 Pro（$19/月，7,500 次/天）。
- 大批量抓取前先用 `/status` 确认当日剩余额度。
