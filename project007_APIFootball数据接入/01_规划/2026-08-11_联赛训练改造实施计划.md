# APIFootball 联赛训练改造实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从 apifootball.com 下载可审计的联赛历史赛果，自动选择样本充足的国内热门联赛进行独立训练，并隔离赛后数据、供应商预测与不同赔率主源。

**Architecture:** 适配器负责 API 协议和原始响应；历史下载器负责日期分块、去重和标准化；审计器只决定联赛分层；训练器只消费审计后的赛前安全数据。API 赔率与供应商预测独立登记，不改变默认体彩链路。

**Tech Stack:** Python 3 标准库、现有 `apifootball_com_adapter.py`、SciPy Dixon-Coles 训练器、pytest。

## 全局约束

- Key 仅从 `APIFOOTBALL_COM_KEY` 读取；日志、异常、原始数据和 Git 中不得出现 Key。
- 所有新增源代码、测试、原始响应、标准化数据和报告放在 `F:\HM足球比赛预测` 的对应项目目录。
- 体彩默认赔率链路不改变；`apifootball_primary` 必须显式选择并标记 `provider_only`。
- `get_predictions` 只作 `PROVIDER_BENCHMARK`，不参与概率融合或 edge 门控。
- 赛前训练输入禁止使用 `POST_MATCH` 字段；违规时必须失败并列出字段名。
- 每个联赛按 kickoff 时间切为 60% train / 20% validation / 20% test。
