# 需求

- 项目名称：APIFootball数据接入（project007）
- 类型：数据/代码类项目（数据源接入）
- 目标：为足球量化融合引擎接入 API-Football v3（`v3.football.api-sports.io`），补充
  伤停、阵容、积分榜、H2H、赛程等 enrich 数据，不替代体彩官方固定奖金链路。
- 交付物：
  1. `api_football_adapter.py`（CLI 适配器，key 只从环境变量读取）
  2. `05_交付/接入说明.md`（用法与限制）
  3. 实测输出 JSON（`04_素材/`）
- 验收标准：
  - `status` / `teams` / `fixtures` / `standings` / `injuries` / `h2h` 六个子命令实测通过；
  - key 不写入任何文件、不出现在输出中；
  - 输出保留 API-Football 信封结构（get/parameters/errors/results/paging/response）；
  - 免费计划（100 次/天）下可用的赛季范围已实测确认并写入文档。
