## 2. 量化轨：22场官方90分钟回测

### 2.1 当前指标

| 指标 | 结果 |
|---|---:|
| 1X2 Top1 | 11/22 = 50.00% |
| 多分类 Brier | 0.619513 |
| Log Loss | 1.024700 |
| 比分 Top1 | 5/22 = 22.73% |
| 比分 Top3 | 10/22 = 45.45% |
| Top-label ECE（3粗粒度置信区间） | 0.266000 |

### 2.2 可诊断信号，不可直接调参

- 模型预测结果方向为主胜15场、平局0场、客胜7场；实际为主胜9场、平局7场、客胜6场。当前样本中平局被系统性忽略。
- Top1比分有13/22为`1-1`，而实际`1-1`并未占相同比例，存在比分Top1集中度风险。
- 置信度40%–59%的10场仅命中2场（20%），但样本很小；60%–79%的5场命中4场也不能当作已校准证明。
- 该轨道是市场基线，不是独立模型；没有同场、同版本、时间顺序的独立实验配对样本，不可称为市场优势。

### 2.3 优化优先级

1. **平局诊断，不立刻改参数**：按联赛、赔率区间、主平客隐含概率和盘口新鲜度切片，积累至少100场同哈希样本后再评估平局校准。
2. **比分反坍缩审计**：每个cohort记录Top1/Top3分布熵、`1-1`占比和实际比分覆盖；比分只作衍生市场，不能反推1X2优势。
3. **独立实验回归**：Understat xG和APIfootball goals-only仅以独立`experiment`身份影子运行，执行walk-forward、同场配对Brier/Log Loss差值与置信区间。
4. **半全场继续空缺**：缺官方`score_ht`时保持`unresolved_missing_official_halftime_score`，不能补算。

## 3. LLM轨评测

### 3.1 已有历史结果

旧证据LLM累计13场：方向单选8/13=61.54%，含双选10/13=76.92%，比分2/13=15.38%，同期官方赔率方向6/13=46.15%。

这些数据不能用于评价当前正式四模型池，原因：

- 历史模型池与当前四模型池不同；
- 历史证据门禁比当前宽松，存在缺口、单源和赛后采集风险；
- 样本13场远低于100场评估门槛；
- 双选覆盖率不是与单选等价的准确率指标。

### 3.2 当前正式四模型池状态

```text
zhipu/glm-4-flash
qwen/qwen3.8-max
 deepseek/deepseek-chat
moonshot/kimi-k2.6
```

- Kimi最小API探针已获HTTP 200，且强制`temperature=1`。
- Qwen3.8-Max已写入代码与治理策略，但当前Hermes进程此前尚未看到`DASHSCOPE_API_KEY`，因此尚未完成真实API探针。
- 当前四模型池没有同版本、证据合格、官方90分钟已结算的样本；性能结论为`not_evaluable_yet`。

### 3.3 LLM优化优先级

1. 先记录每模型单独输出、失败状态、提示词/规则哈希、证据哈希、模型池和温度；不要只留聚合结论。
2. 强制六类证据、URL、`collected_at`和事实行；缺证据不调用LLM。
3. 对`1-1`、`2-1`、`1-2`、`小2.5`、`胜胜`等输出做模型级坍缩率统计；坍缩时降权/强制谨慎双选，不把共识误判为独立性。
4. 使用相同证据、同一冻结时点对四模型做影子逐场记录；达到100场前不调整模型权重。

## 4. 是否吸纳新模型

### 当前结论

**现在不应再直接把更多模型加入正式投票。** 当前瓶颈是可评分、同版本、证据合格样本为0，不是模型数量。

### 可进入影子实验的候选

| 候选 | 价值 | 进入条件 | 现阶段结论 |
|---|---|---|---|
| 腾讯混元 `hunyuan-turbos-latest` | 独立厂商/训练路线；腾讯云提供OpenAI兼容调用示例 | 环境变量、国内直连探针、四玩法JSON契约、30场影子样本 | 推荐为第1影子候选 |
| 豆包/火山方舟通用推理模型 | 国内直连、可增加厂商多样性 | 控制台开通、实际模型ID探针、JSON契约；不得重复接Qwen/GLM/DeepSeek同系模型 | 推荐为第2影子候选 |
| MiniMax通用文本模型 | 官方提供OpenAI Chat Completions兼容接口 | 明确非编码模型、真实API探针、30场影子样本 | 可做第3候选 |

不建议将Groq、Gemini、OpenRouter免费模型直接接入当前生产池：它们依赖海外代理或限流策略，必须独立实验进程。

## 5. 准入门槛

新模型仅在以下顺序全部完成后才可讨论正式投票：

```text
国内直连最小API探针
→ 证据合格单场四玩法JSON契约
→ 30场影子运行（不参与正式聚合）
→ 100场同版本、同证据、官方90分钟结算评估
→ 与当前四模型池按同场配对比较方向、Brier、Log Loss、坍缩率和失败率
→ 200场后才讨论模型权重或正式替换
```
