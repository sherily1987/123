## 三、预测方案（单轨 = LLM 证据轨）

**主预测轨统一用 LLM 证据轨**（`predict.py`，3 模型：glm-4-flash / deepseek-chat / doubao-seed-evolving），理由：量化轨覆盖不全（48 场里 8 场无模型/未训练），且已查过低级别联赛 DC 模型 Log Loss 普遍 ≥ 市场（质量存疑）。

**量化模型只作「覆盖标注」维度**，不实际跑量化预测：

- **① 有量化模型（40 场）**：LLM 轨预测 + 标注「有 Dixon-Coles 模型，可量化对照」。
- **② 有数据未训练（沙职 3 场）**：LLM 轨预测 + 标注「量化模型未训练，仅 LLM 定性」。
- **③ 无量化模型（5 场）**：LLM 轨预测 + 标注「⚠️ 无量化模型，仅 LLM 定性，置信度低」——这 5 场是日乙/德乙/美职/英社区盾，本质是小联赛/杯赛，证据和量化都弱。

**分联赛分组**：按联赛输出，不混排，每个联赛抬头标注量化覆盖状态。
