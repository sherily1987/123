# 手机端运行说明

> 先说清楚一个前提，免得白折腾。

## ⚠️ Claude Code 不能在手机上运行

Skill 是 Claude Code（桌面/终端）的机制。手机上**没有**能加载本地 skill 目录的 Claude Code。

所以「把 Skill 放手机上跑」得拆成两件事：

| 你想要的 | 能不能 | 怎么做 |
|---|---|---|
| 在手机上**算概率** | ✅ **能，而且很稳** | 方案 A：手机装 Python 跑 `predict.py` |
| 在手机上**让 AI 走完整流程**（采数→OCR→审计→写报告） | ⚠️ 不确定 | 方案 B：见下，需要你自己验证 |

---

## 方案 A：手机跑 Python（推荐，确定可行）

**为什么确定**：`predict.py` 和 `backtest.py` **零第三方依赖**，只用了
`argparse / json / math / bisect / csv / glob / os`，全是 Python 标准库。
任何 Python 3 环境都能直接跑，不需要 pip install 任何东西。

### Android

1. 装 **Pydroid 3**（应用商店搜得到）或 **Termux**（F-Droid）
2. 把 `zu-yu-dashi-3` 文件夹传到手机（微信传文件给自己 → 保存到本地）
3. 在 Pydroid 3 里打开 `scripts/predict.py`
4. 准备一个输入 JSON（可改 `scripts/示例输入.json`）
5. 运行：

```
python predict.py 示例输入.json
```

Termux 用户注意加一句避免中文乱码：
```
export PYTHONUTF8=1
```

### iOS

1. 装 **a-Shell**（免费）或 **Pythonista 3**（付费）
2. 同样传文件、同样命令

### 能得到什么

完整的 JSON 输出——胜平负、Top 比分、大小球、BTTS、亚盘五档拆分、
双回合晋级路径、`reliability_flags`、`sensitivity`。

**跟电脑上跑出来的一模一样**，因为是同一份代码、同一套标准库。

### 得不到什么

- 自动采数（要你自己填赔率进 JSON）
- 截图 OCR（要你自己看图录数）
- 自动写报告（输出是原始 JSON，不是 markdown 报告）

换句话说：**方案 A 给你的是计算器，不是助手。**

## 方案 B：claude.ai 手机 App（不确定，需你自己验证）

Claude 的手机 App 和网页版共用账号。**如果**你的账号能上传 Skill，
理论上可以在手机上用完整流程。

**但我没法替你确认这一点**，需要你自己去看：

1. 打开 claude.ai（网页或 App）
2. 找设置里有没有 **Skills / 技能** 相关入口
3. 有的话，试着上传 `zu-yu-dashi-3.zip`

**如果能传上去，还有两个坑要注意：**

- `SKILL.md` 硬规则第 1 条写的是 Windows 路径（反斜杠 `\`）。
  云端环境是 Linux，得改成正斜杠：`python <技能目录>/scripts/predict.py`
- 硬规则第 8 条要求把产物存到 `projectXXX_项目名称\05_交付\...`。
  云端没有你的本地文件夹，这条得改掉或删掉。

**试之前先备份**，别把电脑上能用的版本改坏了。

---

## 方案 C：只带走"算法"，不带走"技能"

如果你只是想随时能算，最省事的做法：

把 `predict.py` 一个文件发到微信「文件传输助手」，需要时在手机 Python App 里打开跑。
**27KB，一个文件，没有任何依赖。**

---

## 我的建议

**先走方案 A。** 它确定能用，而且今天你已经验证过这套代码是对的
（3470 场回测、概率守恒全过）。

方案 B 值得试，但别抱太大期望，也别在没备份的情况下改文件。

**另外提醒**：手机上跑出来的仍然是「复述盘口」的结果。
3470 场回测的结论没变——在只有赔率的情况下，模型打不过市场。
它有用的地方是把盘口拆成亚盘五档、晋级路径这些市场不直接给的量。
