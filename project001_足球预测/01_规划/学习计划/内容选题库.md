> 按周对应你的学习进度。**当周学什么就发什么**，不用提前储备。
> 标题直接可用，正文框架已给出，你只需要填自己的真实经历。

## 通用：小红书标题公式（先看这个）

| 公式 | 例子 |
|---|---|
| **数字 + 结果** | 「学了 3 天 AI Agent，我把 3 小时的活压到 20 分钟」 |
| **身份 + 反差** | 「零基础文科生，7 天搭出了自己的 AI 助手」 |
| **痛点 + 解法** | 「AI 老是瞎编？因为你不懂这个东西」 |
| **踩坑 + 警示** | 「学 AI Agent 别买课！这 3 个免费资源吊打 1999 训练营」 |
| **保姆级 + 可抄** | 「保姆级教程｜零基础 30 分钟搭一个简历打分 AI」 |

**四条铁律**
1. 标题 20 字内，**前 8 个字必须有钩子**（小红书列表页只显示这么多）
2. 封面图：**大字 + 高对比色**，手机截图直接打字，不用做设计
3. 正文开头 3 行定生死——先说结果，再说过程
4. 结尾必须有互动引导：「你卡在哪一步？评论区我看到就回」

**发布时间**：工作日 12:00-13:00 / 19:00-22:00，周末 10:00-12:00

# Week 0 选题｜装环境踩坑（发 1 条）

### 1. 「零基础装 Claude Code，我卡在了这一步」
- **平台**：小红书
- **框架**：装 Node.js → 装 Claude Code → 登录，每一步的报错截图 + 怎么解决的

# Week 1 选题｜观察真 Agent（发 3 条）

### 2. 「AI Agent 和 ChatGPT 到底差在哪？我用点外卖讲明白了」
- **平台**：小红书 + 知乎
- **框架**：ChatGPT = 你问"附近有什么川菜"，它列一堆，你自己去点。Agent = 你说"我想吃辣的，30 块以内，帮我搞定"，它自己搜、比价、下单、告诉你 40 分钟到
- **钩子**：一句话说清"能不能自己动手"这个本质区别

### 3. 「我盯着 AI 干了一小时活，终于看懂它是怎么思考的」⭐独家视角
- **平台**：小红书 + 知乎
- **框架**：Day 3 的观察记录。📸 配图用你截的**每一次工具调用**
- **为什么强**：大部分人只看到 AI 的输出，你展示的是**过程**。ReAct 循环肉眼可见，这个视角中文内容极少

### 4. 「AI Agent 的四个零件，缺一个就变成人工智障」
- **平台**：小红书
- **框架**：大脑/指令/工具/记忆，逐个讲缺了会怎样。缺工具=只会空谈；缺记忆=每次从头问
- **配图**：四宫格，一格一个零件

**备选**：「为什么你的 AI 只会聊天，别人的能干活？」

# Week 2 选题｜指令工程（发 3-4 条）

### 5. 「提示词五段式模板，照着填就行」⭐高收藏
- **平台**：小红书（图文）
- **框架**：角色/任务/约束/输出格式/示例，每段给填空模板
- **为什么爆**：可直接抄的模板类内容，收藏率最高
- **钩子**：结尾「模板整理成文档了，评论区扣 1」→ 导私域

### 6. 「我改了 4 版指令，AI 才终于听话（附每版对比）」
- **平台**：小红书 + 知乎
- **框架**：CLAUDE.md 的 v1→v4 迭代记录，📸 每版行为差异截图
- **为什么好**：**过程比结果打动人**，显真实

### 7. 「大部分教程不讲：给 Agent 写指令要多写这 3 句话」⭐差异化
- **平台**：知乎为主（适合长文）
- **框架**：何时调工具 / 工具失败怎么办 / 什么时候算完成
- **为什么好**：Day 8 学的分水岭知识，**真的很少人讲**，容易立专业感

### 8. 「AI 能直接改你的文件，这个开关一定要知道」
- **平台**：小红书
- **框架**：Plan mode 和权限模式，为什么 Agent 需要护栏
- **为什么好**：安全类内容天然有传播力

# Week 3 选题｜第一个 Bot（发 4 条）★流量周

### 9. 「保姆级｜零基础 30 分钟搭一个简历打分 AI」⭐主推

### 11. 「我做了个 AI 简历打分器，免费用」

- **框架**：纯成品展示 + 效果截图，链接放评论区
- **为什么好**：**引流主力**。工具类免费送最容易涨粉

### 12. 「搭 Bot 卡了 3 小时，就因为这个地方没注意」

- **框架**：Day 13 的踩坑记录

# Week 4 选题｜MCP（发 3-4 条）⭐差异化最强周

### 13. 「MCP 是什么？我用 USB-C 讲明白了」⭐热点
- **平台**：小红书 + 知乎
- **框架**：以前每接一个工具要单独适配（各种充电口），MCP 出来后统一了（USB-C）
- **为什么强**：**热度高但讲清楚的人少**，这是你 6 周里最有差异化优势的一条

### 14. 「我给 AI 装了第一个 MCP，踩了 3 个坑」⭐独家实操
- **平台**：小红书 + 知乎
- **框架**：Day 18 的配置文件截图 + 成功画面 + 每个报错怎么解决
- **为什么强**：**中文里能真动手写这个的人极少**。理论文章满地都是，实操记录几乎没有

### 15. 「装 MCP 前 vs 装完后，AI 的能力差距有多大」
- **平台**：小红书
- **框架**：Day 19 的对比——不用 MCP 同一件事要多做哪些工作
- **配图**：前后对比图，视觉冲击强

### 16. 「AI 凭什么能自己干活？Function Calling 说人话版」
- **平台**：知乎
- **框架**：模型怎么"决定"调工具、怎么填参数

# Week 5 选题｜进阶三件套（发 3-4 条）⭐独家周

## 内容节奏建议

|---|---|---|---|---|

**每周 3-4 条，宁可少不可断。**

## 你的内容护城河在哪

大部分中文 AI 博主讲的是「怎么用扣子/即梦」。**MCP、Skills、Subagents、Hooks 的中文实操内容几乎为零**——不是因为难，是因为大部分博主没在真的用生产级 Agent。

W4 和 W5 是你的独家周，那 8 条选题的竞争度远低于前面几周。攒够素材，慢慢发。

## 前 20 条的心理准备

前 20 条基本没流量，**这是必经期，不是你写得差**。

评判标准不是「爆没爆」，是「**有没有持续发**」。数据难看的时候看这行字。
