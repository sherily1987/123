## 核心认知：你已经拥有一个生产级 AI Agent

**Claude Code 本身就是一个 AI Agent。** 你不是在"学理论"，你是每天在用一个真的。

| Agent 四件套 | 在 Claude Code 里是什么 | 你能怎么观察 |
|---|---|---|
| **大脑** LLM | Claude 模型 | 换模型看行为差异 |
| **指令** Prompt | `CLAUDE.md` + 系统提示 | 你可以自己写、自己改 |
| **工具** Tools | Read / Write / Bash / Grep / WebSearch… | **每次调用都显示在屏幕上** |
| **记忆** Memory | `CLAUDE.md` + memory 目录 | 跨会话保留，看得见文件 |

**ReAct 循环（思考→行动→观察→再思考）你是肉眼可见的**——每次它调工具、看结果、再决定下一步，全过程都在你眼前跑。

这就是为什么这套计划比"在扣子上拆别人的 Bot"强：**你在看一个真 Agent 的内脏，不是在看别人的成品外壳。**

## Week 0｜先把它跑起来（3 天）

**零基础的第一道坎不是 AI，是终端。** 这周只干一件事：让 Claude Code 在你电脑上跑起来。

### 学什么（只学够用的）
终端命令就学 4 个，够用一整个计划：

| 命令 | 干什么 | 记法 |
|---|---|---|
| `cd 文件夹名` | 进入文件夹 | change directory |
| `cd ..` | 退回上一层 | 两个点 = 上一层 |
| `ls`（Windows 也能用） | 看当前有什么 | list |
| `pwd` | 我现在在哪 | print working directory |

**就这些。** 剩下的全部交给 Claude Code。

### 动手做什么
1. 装 Node.js（官网下载，一路下一步）
2. 装 Claude Code
3. 用**订阅账号**登录
4. 在一个文件夹里启动，让它帮你做一件真事（整理文件、写一份文档、生成一张表）

### 产出内容（1 条）
「零基础装 Claude Code，我卡在了哪一步」——📸 **每一个报错都截图**

### 验收标准
✅ 你能独立打开终端 → 进入指定文件夹 → 启动 Claude Code → 完成一次有意义的对话

💡 **卡住了直接把报错粘给我。** 这一周允许全程求助，装环境卡住太正常了。

## Week 1｜观察一个真 Agent 在你眼前跑

**目标**：把概念全部落地。这周不搭任何东西，只观察。

### 学什么
1. **三个词的区别**
   - 聊天机器人：你问一句，它答一句，答完就完
   - 工作流：固定流程 A→B→C，不会变通
   - **Agent**：给目标，它自己决定分几步、用什么工具、做完没有
2. **Agent 四件套**（对照上面那张表，在 Claude Code 里逐个找出来）
3. **ReAct 循环**：思考 → 行动 → 观察 → 再思考

### 动手做什么（这是本周精华）
给 Claude Code 一个**多步骤任务**，比如：
> 「看一下这个文件夹里有什么，把所有 md 文件的标题整理成一个清单」

然后**全程盯着屏幕**，把它的每一步记下来：
- 它先做了什么？（大概率先 Glob 或 ls 找文件）
- 为什么它决定调这个工具而不是那个？
- 工具返回结果后，它下一步变了吗？
- 它怎么知道任务做完了？

📸 **截图每一步的工具调用。** 这是你 Week 1 内容的全部素材。

### 产出内容（3 条）
见 [`内容选题库.md`](内容选题库.md) 第 1 周部分。

### 验收标准
✅ 找个家人朋友，3 分钟讲清 Agent 和 ChatGPT 的区别，对方能听懂。
✅ 你能指着屏幕上任意一次工具调用，说出「它为什么在这一步调这个」。

## Week 2｜指令工程：写你自己的 CLAUDE.md

**目标**：提示词工程最真实的应用场景，就在你手边。

### 学什么
1. **结构化提示词**：角色 / 任务 / 约束 / 输出格式 / 示例
2. **Few-shot**：给 2-3 个例子 > 写 500 字说明
3. **`CLAUDE.md` = Agent 的持久化指令** ⭐
   这是本周核心。CLAUDE.md 是你写给 Agent 的"岗位说明书"，每次启动都会加载。
   你在这里写的每一句，都会真实改变它的行为——**这是能立刻验证效果的提示词实验场**。
4. **Agent 提示词的特殊之处**：要写清楚
   - 什么情况下该调工具、调哪个
   - 工具失败了怎么办
   - 什么时候算完成
5. **Plan mode 与权限模式** = Agent 的安全边界（顺带理解"为什么 Agent 需要护栏"）

### 动手做什么
- 写一份自己的 `CLAUDE.md`（比如规定：回答要简短、代码要加中文注释、不许自作主张改文件）
- **改之前跑一次，改之后跑一次，对比行为差异**
- 迭代 3-4 版，每版都存下来

📸 **保存每一版 CLAUDE.md 和对应的行为变化。** 迭代过程本身就是好内容。

### 产出内容（3-4 条）
提示词模板合集**收藏率最高**——读者会想"先存着以后用"。

### 验收标准
✅ 你改了 CLAUDE.md 之后，Claude Code 的行为**发生了你预期中的变化**。
✅ 同一个指令连跑 5 次，输出格式稳定不跑偏。

## Week 3｜零代码搭第一个 Bot ★里程碑

**目标**：做出一个能发给别人的东西。这周是分水岭。

**为什么还要学扣子？** 两个理由：
1. **面向非技术受众的内容流量更大**——大部分读者不会装 Claude Code，但会用扣子
2. **它是你闲鱼接单的交付工具**——搭好的 Bot 直接提升你的交付速度

### 学什么（扣子三件套）
1. **知识库**：上传文档 → Bot 基于你的资料回答，不瞎编
2. **插件**：给 Bot 装能力（搜索、读网页、生成图片）
3. **工作流**：把多个步骤串起来

### 动手做什么
搭 **「简历打分助手」**：
- 输入：简历 + 目标岗位 JD
- 输出：分数、逐条问题、改写建议

**为什么选这个：** 它直接反哺你的闲鱼接单业务（接到简历单先丢给自己的 Bot 跑初稿），场景人人有需求，复杂度刚好一周做完。

**额外动作（本周最有价值的选题）**：同一个需求，**用 Claude Code 也做一遍**，写对比：
- 哪个快？哪个稳？哪个更适合零基础？
- 什么场景该用哪个？

### 产出内容（4 条）
保姆级教程是涨粉主力形态。**从注册开始截图，不要跳步**——你觉得"这还用讲？"的地方，正是小白卡住的地方。

### 验收标准
✅ Bot 已发布，**发给一个朋友，他不看说明就能用起来**。

## Week 4｜MCP：终于能真·动手了 ★差异化最强

**目标**：搞懂 Agent 凭什么能"真的干活"，并且**亲手接一个上去**。

**这是你 6 周里最有内容优势的一周。** MCP 热度高、能真正动手的人少、中文教程稀缺——而你手上的 Claude Code 原生支持它。

### 学什么
1. **Function Calling**：模型怎么"决定"调工具、怎么把参数填对
2. **MCP（Model Context Protocol）** ⭐
   - Anthropic 2024 年提出，**2026 年已是工具调用的事实标准**
   - 解决什么：以前每接一个工具都要单独适配，现在有了统一接口
   - 类比：**MCP 之于 AI 工具 = USB-C 之于充电线**
3. **权限与安全**：为什么给 Agent 装工具需要谨慎

### 动手做什么（本周核心）
**亲手给 Claude Code 装一个 MCP server 并成功调用。**

从简单的开始（文件系统、浏览器、搜索类的），跑通全流程：
- 配置在哪写
- 装完怎么确认成功
- 调用失败时报什么错、怎么排查

📸 **配置文件、成功调用、失败报错，全都截图。**

### 产出内容（3-4 条）
- 「MCP 是什么，我用 USB-C 讲明白了」
- 「我给 AI 装了第一个 MCP，踩了 3 个坑」

### 验收标准
✅ MCP server 装好，**Claude Code 能成功调用它完成一个实际任务**。
✅ 你能说清楚：不用 MCP 的话，同一件事要多做哪些工作。

## Week 5｜进阶三件套：Skills / Subagents / Hooks

**目标**：Claude Code 独有的进阶能力，中文教程几乎为零——你的独家内容周。

### 学什么
1. **Skills（技能）** = 可复用的能力包
   把一套"做某类任务的标准流程"打包，需要时自动加载。
   💡 你现在读的这份计划，就是我用 Skill 机制查证过技术细节后写的。
2. **Subagents（子代理）** = 多 Agent 协作的现成实现
   主 Agent 把任务分给子 Agent 并行处理——**这就是教科书里的"多智能体系统"，你能直接用**。
3. **Hooks（钩子）** = 事件驱动自动化
   「每次改完文件自动跑格式化」这类规则，由程序执行而不是靠 AI 记住。

### 动手做什么
写一个**你自己的 Skill**。建议做跟闲鱼接单相关的，比如「简历改写标准流程」：
- 定义什么时候该触发
- 写清楚步骤和输出格式
- 测试它能不能被正确触发

### 产出内容（3-4 条）
「Claude Code 的 Skills 到底是什么」「我写了个 Skill，接单效率翻倍」——**这类内容中文几乎没人系统讲过**。

### 验收标准
✅ 你的 Skill 能在正确的场景被自动触发，并按你写的流程执行。

## Week 6｜写第一行代码 + RAG + 收口 ★里程碑

**目标**：破除对代码的恐惧，补上最后一块拼图，打包成能交付的成品。

### 学什么
1. **最低限度的代码**
   - 装环境、跑脚本
   - **怎么读报错** ⭐——这是零基础最该学的一件事，比语法重要 10 倍
   - **把 Claude Code 当私人老师**：你描述需求，它写代码，你负责看懂和验证
2. **RAG（检索增强生成）**
   - 为什么 AI 会一本正经地瞎编（幻觉）
   - RAG 三步：检索 → 增强 → 生成，答案带出处
   - 这是**企业最常见的需求 = 最容易接到的单**
3. **调 Claude API 写你自己的 Agent** ⭐（有预算才做这一步）
   - 拿 API Key，跑通第一个调用
   - 写一个 10-20 行的最小 Agent：给它一个工具，让它自己决定何时调用
   - **这一刻你会真正理解前 5 周看到的一切**——你在扣子上拖的、在 Claude Code 里观察的，底层就是这几行

💰 **本周会产生订阅之外的费用。** Claude API 按 token 单独计费，先充 ¥100 试水足够跑完整周。设一个用量提醒，别开着跑通宵。

### 动手做什么
- 让 Claude Code 带你写一个能跑的小脚本（批量重命名、统计数据都行）
- 遇到报错**先自己读、自己搜**，实在不行再问我
- 拿 API Key，写出你的第一个自主 Agent（Claude Code 全程当你的老师）
- 给 Week 3 的「简历打分助手」接上知识库，让每条建议都说得出依据

### 产出内容（3-4 条）
- 「零基础第一次写代码是什么体验」——**把崩溃的瞬间写出来**，共鸣型爆款
- 6 周复盘 + 「学完能接什么单、什么价」——**变现引流内容**，私域入口放这里

### 验收标准
✅ 遇到一个报错，你能自己看懂、自己搜、自己修好。**一次就行。**
✅ **你自己写的 Agent 能跑起来，并且会自己决定调用工具**
✅ 有一个可对外交付的 Agent 成品
✅ 6 周累计发布 **20 条左右**内容
