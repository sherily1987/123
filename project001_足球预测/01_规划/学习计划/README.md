## 这个计划的两个核心判断

### 1. 你的学习进度，就是你的内容素材

零基础不是劣势，是你最大的资产。已经会的人写不出"第一次装环境时懵在哪一步"，而你的读者正卡在那一步。所以这个计划不是"先学完再想怎么写"，而是**每周学的东西直接变成那周要发的内容**。

人设定死一句话：**「零基础小白学 AI Agent 实录」——不装专家，只记录真实踩坑。**

### 2. Claude Code 本身就是一个生产级 AI Agent

你不是在学理论，你每天在用一个真的。四件套在它身上全都看得见：

| Agent 四件套 | 在 Claude Code 里是什么 |
|---|---|
| **大脑** LLM | Claude 模型 |
| **指令** Prompt | `CLAUDE.md` + 系统提示 |
| **工具** Tools | Read / Write / Bash / Grep / WebSearch…**每次调用都显示在屏幕上** |
| **记忆** Memory | `CLAUDE.md` + memory 目录 |

**ReAct 循环（思考→行动→观察→再思考）你是肉眼可见的。** 这比"在扣子上拆别人的 Bot"强十倍——你在看真 Agent 的内脏，不是别人的成品外壳。

你有预算——那更要讲清楚**哪些花了值、哪些是智商税**。

### 按优先级花

| 优先级 | 花什么 | 大概多少 | 为什么值 |
|---|---|---|---|
| **1** | **保住 Claude Code 订阅** | 已有 | 整套计划的基础设施。**这条永远排第一** |
| **2** | **Claude API 额度**（Week 6） | ¥100-300 起 | 从"用别人的 Agent"到"自己造 Agent"的分界线。**按 token 单独计费，跟订阅是两套账** |

| **4** | 出图工具会员 | ¥30-100/月 | **只有**确定要做视觉内容或接绘图单时才买 |

### 别花的

- ❌ **1999 / 999 的「AI 变现训练营」** —— 微软那门免费课（GitHub 近 2 万星、官方中文版）质量高于绝大多数付费课
- ❌ **「AI 副业资料包」「提示词大全」** —— 99% 是免费内容的搬运打包
- ❌ **「AI 工具终身会员」买断** —— 这领域三个月一代，半年就过时

**一句话**：钱花在**额度和算力**上（让你真的能动手），别花在**信息**上（信息是免费的）。

## 免费资源清单

### 主线教材
- **微软 AI Agents for Beginners** — https://github.com/microsoft/ai-agents-for-beginners
  GitHub 近 2 万星，MIT 开源，**有官方简体中文版**。每课含图文 + 短视频 + Python 示例。
- **Google / Kaggle 5-Day AI Agents Intensive** — 免费，每年开班，含实战 capstone。留意开班时间。

### 实操平台
| 平台 | 用途 | 备注 |
|---|---|---|
| **Claude Code** | 主力学习载体 + 你的私人老师 | 你已有订阅，全程用它 |
| **扣子 Coze** | 零代码搭 Agent | 字节出品，中文界面，插件生态最全。**W3 主战场**，也是你接单的交付工具 |

- ❌ 不要一上来就追新模型、新框架。零基础追新等于原地打转
- ❌ 不要"收藏 = 学会"。每周有验收标准，**做出东西才算过**
