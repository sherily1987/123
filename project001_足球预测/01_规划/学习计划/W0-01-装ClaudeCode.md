```
装Claude Code之前我搜了一圈教程，看完差点劝退。

几乎每篇都是这个开头：
· 先装 Node.js，版本要 ≥18
· 然后 npm install -g 一串命令
· PowerShell 会拦住你，得改执行策略
· 中文可能乱码，要执行 chcp 65001
· 最后建议你干脆上 WSL2

3. 登录
4. 打开，能用了

就这四步。没有终端，没有命令，没有环境变量。

【填：整个过程花了多久？有没有哪一步等得比较久或者愣了一下？
哪怕是"下载花了10分钟""登录那里我不确定该选哪个"也要写，这才是小白视角】

—— 为什么教程都在教命令行版 ——

因为写教程的大多是程序员。

命令行版（CLI）确实更灵活，能配各种参数、接自动化脚本。但那是给已经有开发环境的人准备的。

零基础的人用桌面版，能做的事情几乎一样，省掉的是一整套环境配置的坑。

【填：如果你后来发现桌面版有什么不方便的地方，也写出来。真实的取舍比单方面吹更可信】

—— 唯一要注意的 ——

桌面版和命令行版是两个东西，网上的教程如果一上来让你敲命令，先确认它讲的是哪个版本，别对着 CLI 的教程折腾桌面版。

—— 给同样零基础的你 ——

如果你也想试，不用先学命令行。
先把桌面版跑起来，用出感觉了，再决定要不要折腾 CLI。

我打算用它学 30 天 AI Agent，会一直更。
你卡在哪一步？评论区说，我看到就回。
```
