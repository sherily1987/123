## ① 比分矩阵与半场分布温度校准（本地 46696 场训练）

产出：`score_half_calibration_params.json` / `score_half_calibration_report.md`

- 数据源：football-data 五大联赛 46696 场（含 1X2 赔率），等距抽样 15566 场，train 10896 / test 4670（时间切分 2000-07-28 → 2026-05-24）
- 方法：市场 1X2 比例去水 → λ 反解（DC ρ=-0.08）→ 比分网格温度缩放 p^(1/T) 归一化；半场 = λ×0.45、ρ/2、7×7（与引擎 predict 同口径）
- 结果：
  - 全场比分 T=**1.4**：test LogLoss 2.949→2.912，ECE 0.00135→0.00036，Top1 11.2%
  - 半场比分 T=**1.22**：test LogLoss 2.029→2.009，ECE 0.00322→0.00067，半场1X2 准确率 44.7%
- 状态：参数已产出；**未写入引擎生产路径**，需先做融合引擎回归验证再启用
