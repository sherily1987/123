# 足预大师 3 技能适配复盘

## 遇到的问题

1. Skill 说明硬编码 `/var/minis` Linux 路径，无法直接在 Windows 使用。
2. YAML frontmatter 将 `version` 放在顶层，不符合当前 Codex Skill 校验规则。
3. PowerShell `Get-Content` 显示中文乱码，容易误判源文件已经损坏。
4. `quick_validate.py` 在 Windows 上按系统默认 GBK 读取 UTF-8，首次校验失败。
5. PowerShell here-string 中直接嵌入中文路径会受终端编码影响。

## 可复用方法

1. 判断文件是否乱码时，使用 Python `read_text(encoding="utf-8")` 和 Unicode 断言，不依据终端显示。
2. 修改第三方 Skill 前先记录每个文件的 SHA-256，并保留只读原始来源。
3. 只修改必要文件；如果脚本和参考资料实际正确，不进行批量重写。
4. Windows 上运行 Python 文本工具时设置 `PYTHONUTF8=1`。
5. 向 Python 传递中文路径时使用环境变量，避免在 shell 内联脚本中重复编码。
6. Skill frontmatter 只使用当前规范允许的顶层字段；自定义版本放入 `metadata`。
7. 适配完成后至少验证：Skill 结构、AST、最小输入、完整输入、批量输入、失败输入、概率守恒和路径残留。
