# 足球预测方法论

## 数据分层

### 独立模型层

- 历史90分钟赛果和进球：动态攻防强度、Poisson/Dixon-Coles。
- 历史射门过程：近5/10场射门、射正、禁区内射门、被射门。
- 赛前积分榜：位置、积分、主客场表现，但必须是历史快照。
- 赛前首发/缺阵：先做事实和风险标签，系数需要OOS校准。
- 休息、赛程密度、比赛背景：作为上下文修正。

### 外部对照层

- `get_predictions`：`p_apifootball`官方数学概率，不是真实xG。
- `get_odds`：`external_market`国际市场，不进入独立球队强度训练。

## 比分模型

胜平负需要：

```text
p_home / p_draw / p_away
```

比分需要：

```text
lambda_home / lambda_away
```

比分优先依赖真实进球生成过程，不能只把胜平负概率机械拆成比分。

## 在线适应原则

- 快层：每场正式90分钟赛果后更新近期进球、射门、休息和确认阵容状态。
- 慢层：长期攻防、主场优势、Dixon-Coles参数和概率校准只在walk-forward OOS后更新。
- 单场变化必须有上限；异常时保留旧状态或回退长期先验。
- 每个状态必须有`state_as_of`、`collected_at`、`source`、`state_version`。

## 禁止事项

- 用当前比赛赛后统计预测当前比赛。
- 用赛季结束积分榜预测赛季中间比赛。
- 把普通射门数命名为xG。
- 把官方预测概率当成历史真实xG。
- 赔率进入独立球队攻防训练。
- 未经OOS校准就自动改变生产权重。
