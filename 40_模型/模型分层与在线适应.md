# 模型分层与在线适应

## 当前模型分层

```text
p_model
  ← 历史赛果/动态Dixon-Coles/未来可用独立特征

p_market
  ← 体彩HAD及市场层赔率

p_apifootball
  ← APIfootball官方预测概率

p_fused
  ← 经过安全门的融合结果
```

## 当前状态

- 正式control：`market_only` / `prematch`。
- API动态λ实验：`hybrid` / `api-hybrid`。
- 未完成样本外校准前，实验组不能替换control。
- 当前严格版本已结算样本为0。

## 快层

目标：下一场快速吸收近期状态，但不因单场结果改变长期判断。

更新输入：

```text
recent_goals_for
recent_goals_against
recent_shots
recent_shots_allowed
rest_days
confirmed_lineup_and_missing_players
```

约束：

```text
时间衰减或贝叶斯收缩
单场变化上限
state_as_of < kickoff
异常更新保留旧状态
```

## 慢层

包括：

```text
长期进攻强度
长期防守强度
主场优势
Dixon-Coles rho
概率校准
市场权重
```

只有经过walk-forward OOS和至少100场同版本样本后，才允许重训或改权重。

## 生产路由状态（2026-08-09）

生产路由器：`C:/Users/Administrator/.codex/skills/football-quant-fusion/scripts/production_router.py`

```text
五大联赛 → 开球前滚动Understat xG
指定其他联赛 → 开球前APIfootball Finished历史进球
缺失/未知联赛 → MARKET_BASELINE
```

安全规则：

- 目标比赛自身赛后xG禁止进入预测；
- 所有路由写入`field_meta.production_router`；
- 所有先验写入`adjustment_ledger`；
- `no_future_leakage=true`；
- 生产入口使用显式`--production-route`开关；
- 当前默认生产仍为`MARKET_BASELINE`。

门禁报告：`模型评测/生产路由切换门禁_20260809.json`

