# 模型分层与在线适应

## 双轨架构（2026-08-11 定型）

```text
轨道A 量化融合轨（fusion_predict）
  p_market ← 体彩HAD及市场层赔率（市场锚）
  λ ← 多市场反解（HAD/HHAD/TTG/HAFU）
  比分 ← 双变量泊松（λ3=0.05, T=1.30）
  输出：final_1x2 / top_scores / ou_2.5 / btts / hhad
  门禁：recommendation_gate（banker默认否）；market_only 时市场依赖100%

轨道B LLM证据轨（C盘 football-llm-predictor / predict.py）
  输入：六类赛前证据（伤停/战意/近况/主客天气/赔率/身份）
  聚合：>=3 有效模型可聚合；2 模型仅谨慎双选；<2 不输出方向
  输出：方向（H/D/A可双选）+ 比分偏好 + OU/半全场
  禁止伪概率；只输出定性判断
```

```text

p_apifootball ← APIfootball官方概率（外部对照，不训练）
```

## 快层

```text
recent_goals_for / recent_goals_against / recent_shots / recent_shots_allowed
rest_days / confirmed_lineup_and_missing_players
约束：时间衰减或贝叶斯收缩、单场变化上限、state_as_of < kickoff
```

## 慢层

```text
长期攻防强度、主场优势、Dixon-Coles rho、概率校准、市场权重
只有 walk-forward OOS + 至少100场同版本样本后才允许重训或改权重
```

## 生产路由状态

生产路由器：`C:/Users/Administrator/.codex/skills/football-quant-fusion/scripts/production_router.py`

```text
五大联赛 → 开球前滚动Understat xG
指定其他联赛 → 开球前APIfootball Finished历史进球
缺失/未知联赛 → MARKET_BASELINE（当前默认）
```

安全规则：
- 目标比赛自身赛后xG禁止进入预测；
- 所有路由写入 `field_meta.production_router`；
- 所有先验写入 `adjustment_ledger`；
- `no_future_leakage=true`；
- 生产入口使用显式 `--production-route` 开关。

## 回退顺序

```text
有效快速状态 → 长期模型先验 → MARKET_BASELINE → 阻断输出
禁止无审计地静默从 market_only 切换到 model_first
```

## 门禁要点（predict.py）

- `now >= kickoff` 拒绝（赛后阻断）；kickoff/证据时间必须带时区。
- 主证据六标题编号缺一不可；每条实质事实 source(...)+collected_at(...)。
- MCP 只能作补充，需 match_identity 与体彩ID/主客队一致。
- 赔率异常显式降级；模型池哈希/聚合规则版本随输出记录。
