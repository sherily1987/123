# 跨联赛标尺校准报告（欧战作为评估集）

日期：2026-08-12
脚本：`02_脚本/cross_league_calibration.py`
数据：欧冠 1154 场 + 欧罗巴 1014 场（apifootball.com，2021-07~2026-06）
API 请求：0 次（复用已下载数据）

---

## 结论先说

**各国内联赛的强度评分完全不在同一把尺子上。** 直接拿七个联赛的模型互相比较，
预测欧战比赛的表现**比"按历史频率瞎猜"还差**（Brier 0.6188 vs 频率基线 0.6167）。

给每个联赛加一个标量强度偏移后，Brier 从 **0.6188 降到 0.5482（−0.0706）**——
这是本轮所有改动里最大的单项改善，是滚动重拟合（−0.0120）的近 6 倍。

## 1. 问题从哪来

`fit_model` 把每个联赛的 α 重归一化到均值 0。于是英超中游队和比甲中游队的 α 都≈0，
但两者实力显然不同。**联赛之间的整体强度差在国内比赛里根本不可辨识**——
一支球队只和同联赛球队交手，无从确定本联赛整体处于什么水平。

欧战是唯一让不同联赛球队直接交手的样本，因此是估计这个偏移的唯一数据来源。

## 2. 模型

给每个联赛一个标量强度偏移 `s_L`，约束 `Σs = 0`：

```
λ_主 = exp(adv + (α_主 + s_主联赛) + (β_客 − s_客联赛))
λ_客 = exp(      (α_客 + s_客联赛) + (β_主 − s_主联赛))
```

β 越大表示失球越多，故强联赛的球队 β 要**减**去 s。
α/β 取自各国内联赛已拟合模型并**固定不动**，只拟合 adv 与 s_L（7 个联赛 → 6 个自由参数）。

**对照组也拟合 adv**（只是 s 全为 0），这样改善才能干净地归因到"联赛偏移"，
而不是欧战主场优势的校准。

**防泄漏**：以欧战可用样本的 70% 分位处为 cutoff（2025-03-05）。
国内模型只用 cutoff 之前的国内比赛拟合，偏移只用 cutoff 之前的欧战比赛拟合，
评估只用 cutoff 之后的欧战比赛。

## 3. 样本

| 赛事 | 总场次 | 双方都在七大联赛模型内 | 占比 |
| --- | ---: | ---: | ---: |
| 欧冠 | 1154 | 428 | 37.1% |
| 欧罗巴 | 1014 | 182 | 17.9% |
| **合计** | 2168 | **610** | 28.1% |

拟合 427 场，评估 183 场。覆盖率低是因为欧战还有荷甲、土超、苏超、希超等
未纳入的联赛球队——这也说明**扩充国内联赛覆盖能直接提高本方法的可用样本**。

已验证 `team_id` 跨赛事一致（46 支欧冠球队能对上国内模型），无需名称匹配。

## 4. 结果

| 方案 | n | Brier | log loss | 准确率 |
| --- | ---: | ---: | ---: | ---: |
| naive（当作同一把尺子） | 183 | 0.6188 | 1.0283 | 47.5% |
| **calibrated（加联赛偏移）** | 183 | **0.5482** | **0.9306** | **59.6%** |
| 频率基线 | 183 | 0.6167 | 1.0247 | — |

**naive 连频率基线都打不过**，这是"同一把尺子"假设为假的直接证据。

### 与市场的同子集比较

评估集 183 场里只有 119 场有赛前赔率，下表限定在这 119 场：

| 方案 | Brier |
| --- | ---: |
| naive | 0.6215 |
| **calibrated** | **0.5505** |
| 市场基线 | 0.5571 |

校准后与市场基本持平。⚠️ **但 n=119，0.0066 的差距远在噪声范围内，
不能声称"击败市场"。** 可支持的说法只是"校准后达到接近市场的水平"。

## 6. 局限

1. **评估样本只有 183 场**，置信区间宽。偏移的**排序**比其**具体数值**可信得多。
2. 只覆盖七个联赛。荷甲、土超等欧战常客未纳入，其球队参与的比赛被跳过。
3. 单标量假设：一个联赛用一个数概括，未区分攻防两端可能有不同差距。
4. 偏移固定不随时间变化，实际上联赛间强弱会漂移。

## 7. 建议

1. **凡涉及跨联赛比较（欧战、跨国杯赛、跨联赛转会评估）必须先套用偏移**，
   否则结论方向性错误——naive 连频率基线都不如。
2. 偏移随国内联赛覆盖扩充而重估。每多接一个欧战常客联赛，可用样本和精度都会提高。
3. 训练资产仍标 `candidate`，未替换生产模型，未触碰体彩链路。
4. 下一步可考虑把单标量拆成攻/防两个参数，但需要更多样本支撑。
