# 五大联赛下载与训练

运行：

```powershell
python .\project021_五大联赛APIFootball训练\02_脚本\run_five_league_pipeline.py --project F:\HM足球比赛预测\project021_五大联赛APIFootball训练
```

默认复用已有的有效月度原始响应；需要重新获取时显式加入 `--refresh`。出现月度下载失败时命令以非零退出，但会保留 `05_交付/download_failures.json` 和已成功联赛的材料，修复后重复运行即可续传。

训练产物只会是 `candidate`。没有可验证赛前赔率时，报告中的市场基线为 `UNAVAILABLE`；它们不进入体彩推荐门控，也不构成独立 edge 声明。
