# 低样本球队加权居中方案：代数验证结果（不安全，暂不实施）

日期：2026-08-14
背景：怀疑低样本离群球队（升降级附加赛对手）拖偏联赛零点，进而污染跨联赛偏移估计；
      提议把 `fit_model` 里 `Σα=0` 归一化的简单均值换成按 `weighted_n` 加权的均值
API 请求：0 次

---

## 结论：原方案（换一行代码）不安全，会引入结构性扰动，不实施

## 推导

`fit_model` 拟合后做的归一化：

```python
mean_al = al.mean()
al = al - mean_al
adv = adv + mean_al
```

λ 的定义：`λ_home = exp(adv + α_home + β_away)`，`λ_away = exp(α_away + β_home)`——
**`adv` 只出现在 λ_home 里，不出现在 λ_away 里**。

把 α 整体平移 `-c` 并把 `c` 补进 `adv` 后：
- λ_home 不变（`adv+c` 与 `α_home-c` 抵消）
- λ_away 变为原值乘以 `exp(-c)`——**没有任何东西补偿这一侧**

所以这个"重归一化"从代数上讲**不是无损的重参数化**，λ_away 确实会被扰动 `exp(-c)`。

## 为什么现在看起来"安全"

因为 `fit_model` 的优化目标里有一项软约束 `penalty * al.sum()**2`（`penalty=1e-3`），
它在整个优化过程中就在把**简单和**往 0 拉。所以拟合收敛后，
`mean_al`（简单均值）本来就已经趋近于 0，归一化这一步只是清理浮点残差，
`c` 极小，`exp(-c)` 扰动可以忽略。

**这个"安全"是软约束的副作用，不是设计保证的不变量。**

## 实测：换成加权均值后偏移有多大

用苏超模型实测（`scotland_premiership`，2021-07~2025-01 数据）：

| 量 | 值 |
| --- | ---: |
| 拟合后简单均值 `mean(α)` | 7.19e-17（≈0，软约束已压住） |
| 拟合后加权均值 `average(α, weights=weighted_n)` | **0.4358** |
| 若切换居中方式，`adv` 多吸收的量 `c` | 0.4358 |
| 未被补偿的 λ_away 乘法扰动 `exp(-c)` | **0.647** |

**若直接把归一化那一步的简单均值换成加权均值，全联赛所有球队的 λ_away 会被统一
乘上 0.647——客队进球预期集体砍 35%，而 λ_home 几乎不受影响。** 这不是微小噪声，
是结构性破坏，会让模型整体系统性低估客队进球、抬高主胜概率。

## 为什么会差这么多

优化过程中的软约束只管"简单和为 0"，从未管过"加权和为 0"。这两个量在
存在离群低样本球队时会有实质性差异（离群队 α 绝对值大但权重小，
简单均值受它们影响更明显；加权均值则被高样本量的正常球队主导，
两者的分歧恰恰反映了"哪些球队在定义零点"这件事本身就没对齐过）。

## 真正安全的修法（更大改动，本次不实施）

要真正把"加权和为 0"变成模型的不变量，必须**修改优化目标函数本身**，
把惩罚项从

```python
penalty * al.sum() ** 2
```

换成

```python
penalty * (weighted_n_vector @ al) ** 2
```

`weighted_n_vector` 在优化前就可以算出来（只依赖时间衰减权重和各队出场次数，
不依赖待拟合的 α/β），所以技术上可行。但这是**改变优化过程收敛到的解**，
不是安全的事后重参数化：

- 需要重新验证 L-BFGS 收敛性（新目标函数的曲率不同）
- 需要重新跑同联赛与跨联赛的全套回测，确认没有引入其他副作用
- 影响面覆盖 `fit_model` 的每一个调用方（同联赛训练、滚动重拟合、跨联赛校准全部经过这个函数）

这是一次独立的、需要专门验证周期的改动，不是"一行代码"级别的修复。
本次判定**暂不实施**——上一轮报告里把它形容为"一行代码"是错误的估计，已更正。

## 与第 3 项诊断的关系

本次改动原本是想解决"低样本离群球队污染跨联赛偏移"的问题。但
`2026-08-14_跨联赛极端对阵诊断（负结果）.md` 已经显示，现有跨联赛校准
（k=40 的收缩 + 现状居中）在极端对阵上并没有表现出可测的系统性劣化。
两项诊断合起来看，**没有实证证据支持"当前居中方式正在造成实质损害"**，
优先级应该降低，除非未来有新的具体证据。
