# 五大联赛 APIFootball 历史下载与训练 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 下载并审计五大联赛 2021/22–2025/26 的 APIFootball 已完赛历史，训练逐联赛候选 Dixon-Coles 模型并产出时间顺序验证报告。

**Architecture:** 中央 `project007` 下载器负责可重试、可断点的月度 `get_events` 采集与赛前安全标准化；`project021` 配置五联赛并编排下载、审计、时间切分、训练和报告。核心 `team_strength.py` 只增加可审计的来源标签与验证结束日期，不接入生产推荐链路。

**Tech Stack:** Python 3.11、urllib、JSON/JSONL、pytest、NumPy、SciPy。

## Global Constraints

- 仅使用环境变量 `APIFOOTBALL_COM_KEY`；不得写入文件、日志或提交。
- 历史窗口固定为 2021-07-01 至 2026-06-30；只接受 `Finished` 的 90 分钟赛果。
- 禁止把 statistics、lineup、player_statistics、赛后事件、`get_predictions` 或未证实赛前时点的赔率写入训练行。
- 五个目标 ID 固定为 152、302、207、175、168；只有自动审计层级为 `independent` 的联赛才训练独立候选模型。
- 所有本次产生的原始数据、模型和报告写入 `project021_五大联赛APIFootball训练/`；不修改体彩赔率与推荐门控。
