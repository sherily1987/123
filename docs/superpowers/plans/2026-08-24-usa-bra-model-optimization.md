# 美职联与巴甲模型优化实施计划

> **For agentic workers:** 本计划只产生候选优化结果，不自动改写生产参数。

**Goal:** 在严格滚动样本外口径下，分别优化美职联和巴甲的时间衰减、xG权重与联赛参数，并确认是否真正优于收盘市场。

**Architecture:** 复用现有 `run_full_backtest.py`、`tune_xg_blend.py` 与 Dixon-Coles 强度模型。扫描结果写入项目交付目录，生产模型只有在样本外指标同时改善并通过版本审计后才允许更新。

**Tech Stack:** Python 3、现有量化训练脚本、JSON 报告。

**Spec:** 用户要求开始优化当前落后于市场的美职联和巴甲模型。

## Global Constraints

- Sporttery/收盘市场只作生产基线，不被模型输出替换。
- 不把同一市场赔率反解产生的概率当成独立 edge。
- 只接受时间滚动样本外结果；不能用全量历史调参后再回测同一批数据。
- 优化结果先写 candidate/research，不能自动进入 m4 或生产队列。
