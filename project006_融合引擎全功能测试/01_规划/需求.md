# 需求

- 项目名称：融合引擎全功能测试
- 目标：对 football-quant-fusion 1.4.0（含核心引擎 zu-yu-dashi-3 3.4.4）的全部命令与脚本做功能测试，确认各入口可用/不可用状态。
- 范围：
  1. fusion_cli.py 全部子命令；
  2. 融合层独立脚本（sample_audit / fusion_combo 等）；
  3. 核心引擎依赖脚本（preview/merge/settle/backtest/odds_movement 等）；
  4. 为全部英文函数名补充中文功能注释；
  5. 建立全局统一的函数映射档案（references/function_map.md）。
- 交付物：
  - `05_交付/功能测试报告.md`（逐命令结果与说明）
  - `references/function_map.md`（全局函数映射档案，含中文注释约定）
  - 全部脚本的英文函数名中文注释
- 验收标准：
  - 每个入口至少跑一次并记录通过/失败/阻塞原因；
  - 函数映射档案覆盖 fusion 与 core 全部 .py 脚本的函数；
  - 代码注释只加行，不改变任何逻辑；
  - 全局工作台.md 技能登记指向映射档案。
- 渠道/受众：内部维护（Codex 与用户共用）。
