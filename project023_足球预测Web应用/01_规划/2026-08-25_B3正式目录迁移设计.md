# B3 工作台正式目录迁移设计

## 目标

将当前运行于 `.worktrees/b3-web-workbench/project023_足球预测Web应用` 的 B3 工作台提升到正式目录 `project023_足球预测Web应用`，使日常启动、停止、测试和维护不再依赖临时 Git 工作树。

迁移只改变 Web 工作台代码和本地 UI 运行位置，不改变量化模型参数、预测登记、官方赛果、策略快照或共享事实库。

## 当前问题

- 正式目录仍保留旧工作台实现和废弃启动器。
- 当前 B3 服务从 `.worktrees/b3-web-workbench` 启动，删除工作树会导致入口失效。
- 本机同时存在 8765 旧服务和 8766 B3 服务，容易打开错误版本。
- B3 已被修正为读取正式主工作区的量化引擎，但 Web 运行代码本身尚未提升。

## 迁移范围

### 纳入

- `02_脚本` 下的 B3 Python 运行代码。
- `static` 下的 B3 页面、样式、脚本、图标和前端测试。
- B3 启动、停止和运行身份管理代码。
- B3 后端测试与验收接口。
- 当前 B3 的 SQLite 任务数据库，迁移前生成可恢复备份。
- B3 README 和正式启动说明。

### 排除

- `.pytest_cache`、`__pycache__`、运行时 PID 文件和日志。
- `.superpowers` 设计预览与临时服务器状态。
- 临时截图和非交付调试产物。
- 工作树中的 `project018` 副本；正式 B3 必须继续读取主工作区 `project018`。
- 概率参数、版本清单、发布锁、预测登记、回测结果和每日策略快照。

## 数据与路径

- 量化引擎：`F:/HM足球比赛预测/project018_技能工作区整合/02_脚本/skill/football-quant-fusion/scripts`。
- 共享事实库：`F:/HM足球比赛预测/project018_技能工作区整合/04_素材/shared-data/football-quant-fusion`。
- 正式 Web 代码：`F:/HM足球比赛预测/project023_足球预测Web应用/02_脚本`。
- UI 任务数据库：迁移前备份正式目录和工作树两份 `app.db`；以当前 B3 数据库作为迁移后的活动数据库。
- 任何路径解析均不得包含 `.worktrees`。

## 启动设计

- 新入口：`project023_足球预测Web应用/启动B3工作台.bat`。
- 新入口只调用正式目录下的 `02_脚本/launch.py`。
- 启动器验证 B3 UI 契约、构建身份、进程 ID 和端口归属。
- 优先使用 8766；若端口冲突，使用启动器现有的受控端口选择逻辑并显示实际 URL。
- 正式提供对应停止入口，只停止身份和 PID 均匹配的 B3 进程。
- 旧 `启动工作台.bat` 不再启动旧应用，改为显示废弃提示并转交新入口，避免旧快捷方式静默打开错误版本。

## 迁移步骤

1. 记录正式目录与工作树的文件清单、Git 状态和运行进程。
2. 为迁移行为建立失败测试：正式入口不得引用 `.worktrees`，版本接口必须读取主工作区量化代码。
3. 备份两份 `app.db`，停止已验证身份的 8765/8766工作台进程。
4. 将 B3 交付文件选择性提升到正式目录，排除缓存和运行状态。
5. 调整正式目录的路径解析和构建身份。
6. 从正式目录启动 B3，生成新的正式运行状态。
7. 验证接口、页面、策略账本、版本签名和任务数据库。
8. 保留工作树用于回滚，但正式入口与服务不再引用它。

## 错误处理与回滚

- 文件提升前保存正式目录差异清单与数据库备份。
- 若正式 B3 无法通过测试或健康检查，不删除工作树；停止失败服务并恢复原数据库。
- 不使用 `git reset --hard`、`git checkout --` 或递归删除。
- 不覆盖共享事实库和模型配置。

## 验收标准

- 正式启动器中不存在 `.worktrees` 路径。
- B3 服务进程的工作目录位于正式 `project023`。
- `/api/ui-contract` 返回 `version=b3` 和正式目录构建身份。
- `/api/version-governance` 的概率签名与正式 CLI 一致，发布锁为 `MATCH`。
- `/api/daily-strategy/backtest` 保留当前娱乐策略待结算账本。
- 后端相关测试和前端 Node 测试通过；任何既有无关失败单独披露。
- 8765旧版服务停止，不再作为工作台入口。
- 新启动器可重复启动而不产生重复服务，停止器只终止匹配的 B3 进程。

## 非目标

- 不在本次修改模型、校准参数、推荐门禁或策略金额。
- 不合并不同概率签名的样本。
- 不删除 Git 工作树或历史代码。
- 不发布到局域网或公网。
