# 足球预测 Web 工作台 B3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变模型、数据口径、数据库和现有 API 语义的前提下，把 project023 重构为 B3“深色侧栏 + 明亮内容区”的模块化足球预测工作台。

**Architecture:** 保留 FastAPI 与原生 HTML/CSS/JavaScript，先复制当前页面为只读回滚入口，再把主入口拆为应用壳、共享状态/API/组件以及九个页面模块。页面优先组合现有接口，所有异步模块独立失败、缓存最近成功结果，任务运行通过统一任务中心轮询。

**Tech Stack:** Python 3.11、FastAPI、pytest、原生 ES Modules、CSS Custom Properties、Node.js 内置 `node:test`、浏览器本地冒烟测试。

**Spec:** `project023_足球预测Web应用/01_规划/2026-08-25_Web工作台B3重设计规范.md`

## Global Constraints

- 不修改融合模型、推荐阈值、赔率来源、登记/结算口径、数据库结构或后端业务规则。
- 不引入 React、Vue、npm 前端依赖或新的构建链。
- 保持 `/api/board`、`/api/matches`、`/api/late-info`、`/api/daily-strategy`、`/api/daily-strategy/backtest`、`/api/history`、`/api/version-progress`、`/api/version-governance`、`/api/match/{match_id}`、任务 POST、`/api/run/{run_id}` 与导出接口兼容。
- `market_only`、量化概率、LLM 投票、娱乐策略、生产门控和 90 分钟赛果必须分清语义；不得把同源市场概率描述成独立 edge。
- 所有新增文件只放在 `project023_足球预测Web应用` 内；不得改名或移动 project018 的依赖目录。
- 现有未提交文件属于用户；每一任务只暂存明确列出的文件，不使用 `git add .`。
- 桌面优先，约 1024px 与手机窄屏仍可完成核心操作；颜色必须配文字或图标。
- 所有动态文本先转义；缺失值显示原因，不用 `0`、空字符串或假状态代替。
