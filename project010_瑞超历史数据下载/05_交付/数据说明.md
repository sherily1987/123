# 瑞超（Allsvenskan）数据说明

## 1. 数据内容

- 来源：API-Football v3（`/fixtures?league=113&season=Y`），免费计划
- 赛季：2022、2023、2024（免费版开放上限）
- 场次：726 场（每季 242 场 = 30 轮常规赛 + 升降级附加赛）
- 状态：全部 726 场完赛（FT），均带比分

## 2. 文件

| 文件 | 说明 |
| --- | --- |
| `04_素材/apifootball_raw/allsvenskan_2022/2023/2024.json` | API 原始信封 |
| `04_素材/标准化/allsvenskan_results_2022_2024.csv` | 统一建模格式 |

CSV 字段与韩职/挪超/芬超一致：`competition, season_end_year, date, home, away,
home_goals, away_goals, status, source`，可直接合并建模。

## 3. 刷新方法

```powershell
python 02_脚本\fetch_allsvenskan_apifootball.py            # 默认 2022-2024
python 02_脚本\fetch_allsvenskan_apifootball.py --delay 0  # 已拉过时快速重合并
```

免费版赛季范围变化或升级后，修改 `SEASONS` 重跑即可（幂等、断点续传）。

## 4. 口径提醒

- 本数据为赛果/比分，供强度与比分建模；竞彩回测仍须走体彩官方赔率登记链。
- 瑞超是夏季联赛（3–11 月），与挪超/芬超同季，可一并作为北欧联赛建模样本。
