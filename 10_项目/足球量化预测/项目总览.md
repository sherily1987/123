# 项目总览

## 目标

构建一个可审计、可回测、可回退的足球胜平负与比分预测系统：

```text
市场基线
+ 历史赛果动态球队强度
+ 射门过程特征
+ 历史积分榜快照
+ 首发/缺阵
+ 外部官方模型
+ 国际市场对照
```

## 当前架构

```text
体彩采集
  → fusion input
  → APIfootball原始增强
  → 赛前特征构建
  → fusion_predict
  → prematch登记
  → 官方赛果回填
  → fusion_backtest
```

## 当前生产边界

- 默认`market_only`，市场依赖度可能为100%。
- 未完成OOS校准前，动态λ只在实验组`api-hybrid`验证。
- `get_predictions`输出`p_apifootball`，不是xG。
- `get_odds`属于市场层，不进入独立球队强度训练。
- 赛后statistics、赛季结束standings、赛后lineups不能作为当前比赛赛前特征。
