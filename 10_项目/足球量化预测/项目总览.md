# 项目总览

## 目标

构建可审计、可回测、可回退的足球胜平负与比分预测系统，双轨独立并对照：

```text
轨道A 量化融合轨：市场基线 + 多市场反解 λ + 校准
轨道B LLM证据轨：六类赛前证据 + 多LLM定性聚合（不伪概率）
```

## 当前架构（2026-08-12）

```text
体彩采集（project015 fetch_sporttery_full.py）
  → 轨道A: fusion input → fusion_predict → MARKET_BASELINE
  → 轨道B: 六类证据 → predict.py 门禁（赛前/来源/身份）→ 多模型聚合
  → 双轨并列输出 → project021/05_交付/每日开售预测/<日期>/
  → 赛果回填 → fusion_backtest / 待回测记录
```

## 生产边界

- 轨道A 默认 `market_only`，市场依赖度可能为100%；未完成OOS校准前不宣称独立edge。
- 轨道B 只输出方向（H/D/A，可双选）与比分偏好，禁止伪概率；`>=3` 模型才聚合，`<2` 不输出方向。
- 所有预测必须赛前：`now < kickoff_iso`，带时区；主/MCP/Crawl证据也必须在开球前采集。
- 赛后statistics、赛季结束standings、赛后lineups不能作为赛前特征。
- Crawl4AI 只做网页证据采集层，不预测、不绕过 predict.py 门禁。
