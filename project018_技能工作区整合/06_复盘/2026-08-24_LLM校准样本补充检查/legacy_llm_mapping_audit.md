# 历史 LLM 样本映射审计（探索性，不进入生产校准）

## 结论

`parsed_2026-08-15.json` 的 48 条旧预测可以通过同批
`raw_2026-08-15.json` 的 `match_num` 唯一映射到 Sporttery `match_id`。
其中 34 条在官方赛果库已有 90 分钟赛果，14 条尚无可核验赛果。

但这批记录缺少 `prediction_as_of`、正式模型身份和规范的单模型输出契约，
因此本报告只作探索性诊断，不能写入 DeepSeek 校准分母，也不能用于下注门控。

## 不迁移原因

1. 预测时间缺失，无法证明所有输入均在开球前可用；
2. 模型身份和版本不完整，不能与 DeepSeek V4 Flash 混合校准；
3. 半场赛果缺失，HAFU 不能补算；
4. 旧版部分市场字段来自旧解析逻辑，不能回填当前独立市场契约。

后续若要纳入正式校准，必须重新运行带 `match_id`、`prediction_as_of`、证据快照哈希和
模型 ID 的预测，不能仅靠场次号补历史字段。
