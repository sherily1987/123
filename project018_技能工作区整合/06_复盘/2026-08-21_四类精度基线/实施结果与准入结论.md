# 四类预测精度改造：实施结果与准入结论（2026-08-21）

## 结论

本轮完成了胜平负、比分、大小球、半全场的独立评测与研究候选验证。经同源、严格按比赛日切分的测试，**比分和大小球的共享 BP 参数已发布为 `m4`**；体彩仍是唯一生产盘口。胜平负与半全场没有因本次发布而改变。

此前缺失的比分矩阵指标、大小球分母、可审计半场真值与四类独立准入门禁已经补齐；未达到样本门槛的输出仍会按同一把尺子继续积累，而不会借用 m4 的证据放行。

数字的负号均表示候选减基线，较低更好。m4 的结论来自同源的单次时间外切分，不应外推为所有联赛、所有赛季均必然提升；后续仍要按 m4 独立结算样本复核。

## m4 发布范围

- 只改 `SCORE_LAMBDA3: 0.05 → 0.20`，影响完整比分矩阵、Top 比分、O/U、BTTS 与其他由同一比分矩阵聚合的研究性衍生输出。
- 胜平负仍走原来的 Dixon-Coles/市场校准路径，数值未改；半全场仍是 `UNFITTED`，未被 m4 放行。
- 版本从 `m3` 升到 `m4`，发布锁概率签名为 `5c34721daa91…`；外部物理核心副本已与仓库事实源做 SHA-256 一致性核验。
- `m4` 正式 cohort 从 0 场开始。旧 m3/m1 的“重放等价”只限其各自验证的目标版本；不会因为胜平负路径未变，就把旧比分/大小球样本错误算入 m4。
- 温度不是排名优化：`SCORE_TEMPERATURE_FT` 只缩放 Top 比分显示概率，因其为单调变换，不会改变 Top1/Top3 排名。此前混用温度与完整比分矩阵的研究结论已废弃。

## 胜平负：本轮未发布的候选

- 默认平局修正曾按 proportional 去水拟合，而当前生产去水方法是 power。已用同一体彩历史作严格日切分重新检验默认 `OTHER` 联赛的 K/T 网格；训练最优候选在测试集中 **对数损失与 Brier 都变差**，即使 0.5 阈值命中率从 55.36% 升至 55.86%，也只是约两场的阈值波动，不能当作概率模型提升，因此未发布。
- 独立强度 hybrid 现有 38 场配对样本相对同场市场仍为正信号（Brier -0.014591、log loss -0.023069），但不足以切换生产。后续影子运行会对同一场、同一独立 prior 同时记录市场权重 0.40/0.50/0.60/0.70/0.80；每个权重将独立配对评测，避免只记录一个任意权重而无法选择。

## 半全场真值与边界

- 半场比分从 APIFootball 原始赛果单独采集，不从全场比分反推。
- 仅当主客队、开球时间（±30 分钟）、90 分钟全场比分都匹配，且半场比分完整时，记录才标为 `verified`。
- 证据文件：`04_素材/shared-data/football-quant-fusion/research/half-time-evidence/apifootball_verified_20260821.json`。
- 正式半全场结果仍不接收 `UNFITTED` 预测；68 场温度比较是明确命名的研究影子实验，不能被报成正式回测成绩。

## 后续触发条件

1. 每轮结算后运行半场采集与核验，继续累积同一来源、同一匹配规则下的样本。
2. 达到每类门槛后才复核：胜平负 100、半全场 200；比分和大小球应按 m4 新 cohort 重新积累，不与 m3 混算。
3. 即使达到门槛，也必须在相同赛前快照和独立基线下证实改善，再创建新的版本候选、运行发布锁与版本一致性审计。
4. 不得把国际赔率、外部历史 CSV 或 LLM 投票比例直接作为体彩生产概率或凯利依据。
