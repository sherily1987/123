# 模型改造 1–6 实施结果（2026-08-21）

## 结论

本轮完成的是**研究评测、数据时间边界与训练质量门禁**，没有修改 m3 的概率输出，也没有开启新的生产推荐。生产版本仍为 `m3`，发布锁与当前概率签名一致。

## 已落地

1. **版本队列**：经重放验证的同版本等价签名不再被误报为 `signature_drift`；未经验证的签名仍会告警。
2. **hybrid OOS 评测**：新增同场配对的 Brier / log loss、固定种子 bootstrap 区间和排除原因。仅接受赛前、非 `market_derived`、有独立先验且有 90 分钟核验赛果的影子样本。
3. **盘口移动侧车**：新增预测时点之前的去水 1X2 变化特征，仅写 `research.odds_movement`，不改量化概率或生产登记。
4. **强度训练门禁**：训练拟合不收敛、存在非有限参数或向量维度不一致时，结果为 `training_rejected` 且不写候选文件。通过数值门禁的模型也只写 `candidate`，仍需 OOS 分档和人工审核。
5. **国际赔率快照**：新增 T-24h / T-6h / T-75m 计划器、标签持久化和 PowerShell 调用入口。仅 The Odds API 可执行；其他 provider 明确跳过。2026-08-21 dry-run：16 场均未到采集窗口，零接口请求、零赔率库写入。
6. **生产准入**：hybrid 只有同时满足最小样本、Brier 与 log loss 相对同场市场均改善、两个置信区间上界均小于 0，才会得到 `ELIGIBLE_FOR_HUMAN_REVIEW`；任何结果都不会自动切换生产或推荐。

## 当前证据边界

- 当前 m3：已结算 64 场、在途 51 场；全部结算后预计 115 场。距离 100 场重校准门槛仍差 36 场，距离 200 场阈值复审差 136 场。
- 历史可用的 independent hybrid 配对样本为 38 场，早期点估计优于市场，但不满足最小 100 场要求，准入报告仍为 `BLOCKED`。这不是生产优势证明。
- 本轮没有重训或覆盖历史候选文件；历史上德甲与丹麦超的未收敛产物继续保留作审计对象，后续重训会被新门禁拦截。
- 逐联赛 half-life 仍默认 500。只有写明 held-out OOS（样本至少 120、Brier 改善）并经人工审核的策略才允许覆盖；rho 仍锁定，因为改它会改变概率输出，必须走单独的版本化候选实验。
