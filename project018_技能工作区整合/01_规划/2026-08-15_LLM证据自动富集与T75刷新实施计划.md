# LLM 证据自动富集与 T−75 刷新实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 自动把最近5场和体彩 CRS/TTG/HAFU 加入 LLM 证据，并在 T−75 分钟自动刷新伤停与首发且保留旧快照。

**Architecture:** 新建 `llm_evidence_enrichment.py` 承担纯渲染、API-Sports 规范化、刷新到期判断和快照写入；现有 `mcp_evidence.py` 只负责调用与编排。C 盘生产版和 F 盘仓库版使用相同行为接口，保留各自已有差异。

**Tech Stack:** Python 3 标准库、API-Football v3、pytest、Windows/POSIX 兼容文件替换。

## Global Constraints

- 体彩数据必须原样来自 raw，不能手算或用国际市场替换。
- 伤停/首发 0 条标 `UNAVAILABLE`，不能解释为无人缺阵。
- fixture 必须按双方名称、日期和开球时间唯一核验，不能模糊猜测。
- 刷新只允许在 `0 < kickoff-now <= 75分钟`，开球后禁止。
- 旧 canonical 必须归档到 `snapshots/`，预测器仍只读取唯一 canonical。
- 不修改量化概率、`model_version` 或 `probability_signature`。
