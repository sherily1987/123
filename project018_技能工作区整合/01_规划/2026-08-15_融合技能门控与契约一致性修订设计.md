# 融合技能门控与契约一致性修订设计

## 目标

把 `football-quant-fusion` 从“文档谨慎、代码宽松”的状态修成失败关闭：市场基线、数据风险、未校准衍生盘和实验先验都不能被包装成正式出胆，同时让版本身份准确反映概率、决策策略和证据链的不同变化。

## 已确认的问题

1. `MARKET_BASELINE` 与 `AVOID_DATA_RISK` 只要最高概率达到 50% 仍会 `banker_allowed=true`。
2. `_calibrated_primary()` 的结果没有参与最终门控，`confidence_pct` 实际是原始最高概率。
3. HHAD 一球胜风险超过 18% 时只写 warning，仍可出胆；HHAD 本身也没有独立校准。
4. `production_router.py` 能改变 λ 和概率，却不在 `probability_signature`；推荐策略反而被错误纳入概率签名。
5. `EXPERIMENTAL_NOT_PROMOTED` 先验会默认切换到 `hybrid`，实验边界名实不符。
6. SKILL 把概念意图写得像 CLI 子命令，且对全赛事覆盖、缺失市场、人工复核和固定样本阈值表述过度。
7. LLM 证据链已有独立生产实现，但融合 CLI 没有明确入口。

## 设计决策

### 1. 推荐门控失败关闭

- 配置增加 `production_recommendations_enabled=false`；在同版本赛前样本和独立校准未通过正式评审前，所有 `banker_allowed` 为 false。
- 即使未来显式启用，也必须同时满足：`EDGE_REVIEWABLE`、edge 超过敏感性、市场依赖低于策略上限、市场不陈旧、校准概率存在并达到阈值。
- 输出同时保留 `raw_primary_probability` 和 `calibrated_primary_probability`；`confidence_pct` 只允许等于校准概率，不能复用原始概率。
- `MARKET_BASELINE`、`AVOID_DATA_RISK`、`UNFITTED_NO_VALUE`、`EDGE_BELOW_UNCERTAINTY` 全部失败关闭。

### 2. HHAD 独立门控

- HHAD 未有独立校准工件前永远不出胆，只输出 `raw_primary_probability`、方向和风险。
- 对 -1 让球：当主推让负且让平概率达到策略阈值时，增加明确阻断原因；不再出现“警告但放行”。
- 删除文档中“风险超过阈值仍可出胆”的矛盾示例。

### 3. 三类版本身份

- `probability_signature`：哈希所有能改变概率数值的内核、融合变换、生产路由和概率配置。
- `decision_policy_signature`：哈希推荐策略代码与配置。
- `evidence_pipeline_signature`：哈希采集和特征构造代码。
- 本轮默认生产路由行为改变，升级 `model_version` 为 `m2`，技能/融合版本为 `1.5.0`，融合 schema 为 `1.4.0`，重新生成发布锁。

### 4. 实验路由隔离

- `--production-route` 保持兼容，但只附加影子候选，不改 `mode`、不写 `lambda_prior`。
- 新增 `--research-route` 才允许实验先验进入 `hybrid`；结果强制 `research_only=true`，不能作为正式生产登记。
- 最近历史门槛改为双方各自至少 `min_history` 场，输出双方样本数。
- 去掉未验证的固定 `0.9` 缩放，候选只保留透明的攻防均值合成。

### 5. SKILL 与 CLI 一致

- frontmatter 只保留 `name`、`description`，描述以 `Use when...` 开头并说明真实触发范围。
- 明确“意图模式不是 CLI 子命令”，给出每种意图对应的真实命令。
- 正式生产数字必须由版本化脚本生成；人工计算可作为 `manual_check` 复核，但不得覆盖生产字段。
- 市场缺失时输出状态，不强制伪造完整结果。
- 100/200 只作为复审触发点，不作为优于市场的统计证明。
- 新增 `llm-evidence` CLI 路由，显式调用独立 LLM 证据生产目录；失败时明确报路径缺失。

## 测试策略

- 推荐策略：先写会在现状失败的负向测试，覆盖 market baseline、data risk、无显著 edge、未启用、HHAD未校准和一球风险。
- 版本身份：断言三类签名存在、长度完整、职责文件集合正确。
- 路由：断言默认只生成影子候选、双方样本不足分别拒绝、research route 才进入 hybrid。
- CLI：断言 `record --help` 可用、`llm-evidence` 能正确委托。
- SKILL：静态契约测试检查 frontmatter、真实命令、缺失市场语义、manual_check、统计阈值表述和禁止 market-only 出胆。
- 最后运行完整融合测试、project007/project021 回归、版本审计和真实行为冒烟。
