# 融合技能门控与契约一致性修订实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复自动出胆、版本身份、实验路由和 SKILL 契约的不一致，使生产行为默认失败关闭且可审计。

**Architecture:** 推荐策略只负责决策并单独签名；概率签名覆盖全部数值变换；实验先验默认只生成影子候选；SKILL 只描述真实可执行能力。C 盘 active skill 是仓库目录的 junction，因此只修改仓库唯一事实源。

**Tech Stack:** Python 3、pytest、JSON 配置、Markdown 技能契约。

## Global Constraints

- 保留体彩作为唯一竞彩生产赔率源。
- 不把市场方向或原始概率命名为校准置信度。
- 研究先验不得进入正式登记。
- 缺失市场输出状态，不补造数字。
- 保留用户工作区中与本任务无关的修改。
