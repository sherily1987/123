# LLM 证据提示词中性化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 LLM 对比轨使用中性、可弃权、可验证证据引用的紧凑提示词和输出契约。

**Architecture:** 在 `predict.py` 中把 Markdown 证据转换为带 ID/状态的结构化证据块，并将合法 ID 与状态传给解析器。`llm_prompt_rules.py` 只提供中性角色与紧凑 JSON 契约。聚合层跳过 `abstain`，同时保留完整审计记录。

**Tech Stack:** Python 3.14/3.11, `unittest`/`pytest`, OpenAI-compatible Chat Completions API.

- 旧 JSON 有 `direction` 时仍兼容为 `decision=opinion`。
