# LLM 证据提示词中性化设计

## 目标

将 LLM 对比轨从“被人设引导、缺证据也必须猜”改为“中性提示、逐项引用证据、证据不足可弃权”。LLM 轨仍为定性研究轨，不输出伪概率、伪 xG 或基于投票比例的投注 EV。

## 范围

修改 C 盘实际运行副本与 F 盘仓库副本的：

- `llm_prompt_rules.py`：中性系统规则和输出契约。
- `predict.py`：证据编号、证据状态、提示词组装、输出解析与聚合弃权处理。
- `test_prompt_rules.py` / `test_prediction_p0.py`：新行为回归测试。

不修改量化概率引擎、历史预测记录、已登记的 LLM 预测或体彩数据。

## 核心设计

### 1. 统一中性角色

删除“平局/低比分比想象中多”、“无大战证据优先低比分”、“专猎冷门”等预设方向。各模型接收相同的中性规则：先列可验证事实，再列冲突和缺口，最后决定是否足以输出某个市场的定性方向。

### 2. 允许逐市场弃权

输出字段 `direction`、`alt_direction`、`score_pref`、`ou25`、`hafu` 允许 `null`。新增 `decision`，只能为 `opinion` 或 `abstain`。当方向未获得足够证据时，`decision=abstain` 且 `direction=null`；即使胜平负可以给方向，没有进球或半场证据时也应对比分、大小球或半全场单独弃权。

### 3. 证据 ID 与状态

提示词将证据中每条事实编为 `E1`、`E2` 等，并附带状态：

- `VERIFIED_MULTI_SOURCE`：同一事实有两个独立来源一致。
- `SINGLE_SOURCE`：只有一个来源。
- `UNAVAILABLE`：来源无记录或字段不提供，不得反向推断。
- `SOURCE_CONFLICT`：来源冲突，不得用于支持方向。

LLM 必须在 `evidence_ids` 中引用有效 ID。解析器拒绝不存在的 ID；只引用 `UNAVAILABLE`/`SOURCE_CONFLICT` 时不能形成 `opinion`。原先无条件显示的“来源已交叉验证”将被删除。

### 4. 紧凑输出

使用一个简短 JSON 契约：

```json
{
  "decision": "abstain",
  "direction": null,
  "alt_direction": null,
  "score_pref": null,
  "ou25": null,
  "hafu": null,
  "evidence_gap": true,
  "evidence_ids": ["E1"],
  "unsupported_assumptions": [],
  "reason_codes": ["LINEUP_UNAVAILABLE"],
  "summary": "身份可核验，但阵容与状态不足以支持独立方向。"
}
```

删除大段比分枚举、重复警告和强制 60–100 字的自由推理。本地解析器仍负责校验合法比分、方向与大小球的基本一致性。

### 5. 聚合和风控

- `abstain` 不参与方向投票，但保留在审计记录。
- 有效 `opinion` 少于现有最低要求时，整场聚合输出 `insufficient_model_responses`。
- 有明示证据缺口时，不将投票强度当成概率，也不生成投注建议。
- 历史兼容：解析器继续接受旧版有 `direction` 的 JSON，映射为 `decision=opinion`；新生产调用只使用新契约。

## 同步策略

C 盘生产副本比 F 盘仓库副本更新，存在 EV 风控、模型权重、次回合解析等差异。本轮以 C 盘实际生产版为行为基线，先在生产副本完成 TDD，再将受控文件及对应测试完整同步到 F 盘仓库副本。不用 F 盘旧文件反向覆盖 C 盘生产功能。

## 验收标准

1. 四个生产角色提示不再含低比分、平局、主胜、冷门等预设方向。
2. 无足够证据的新格式 `abstain` 能解析，不参与投票。
3. 无效证据 ID 或只用不可用/冲突证据支持方向时，解析器拒绝或降级为弃权。
4. 提示词不再声称所有来源已交叉验证。
5. 比分、大小球、半全场在缺少对应证据时可分别为 `null`。
6. C/F 两份受控代码与测试一致。
7. 生产 LLM 单测、仓库副本单测、融合技能回归和版本概率签名审计全部通过；该框架修改不得改变量化概率签名。

## 不做的事

- 不调整量化模型、市场权重或校准系数。
- 不回写或重算已登记预测。
- 不在本轮修复 Kimi 网络超时架构；只通过精简提示词降低不必要的输入和推理负担。
