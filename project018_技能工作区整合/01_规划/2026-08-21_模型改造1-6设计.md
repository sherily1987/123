# 模型改造 1–6 设计

## 目标

在不改变 m3 生产概率、体彩生产锚和推荐关闭状态的前提下，建立可归因的样本窗口、影子 hybrid 配对评测、盘口时序研究、强度模型质量门槛和国际赔率快照链路。只有通过独立样本外双指标验证后，系统才可获得人工评审生产融合的资格。

## 不变约束

- 生产 1X2 继续使用体彩盘口；国际赔率仅用于研究、盘口移动与 CLV 对照。
- 所有新字段写入 `research` 或训练候选产物，不能修改生产 `final_1x2_pct`，不能创建 m4。
- `production_recommendations_enabled` 保持 `false`；任何自动化均不能切换它。
- 任何使用赛前特征的计算只能选择 `collected_at <= prediction_as_of` 的快照；无可用快照必须写 `UNAVAILABLE`，不能补算或回填。
- 强度参数不做全联赛统一调参。每个例外必须包含独立 OOS 证据、适用范围与回退配置。

## 改造范围

### 1. m3 窗口冻结和等价归因

发布锁与 m3 当前签名一致后，禁止改动概率文件。`version-progress` 必须把 manifest 中经过重放验证的 `(model_version, probability_signature)` 精确别名算入 current，而不是同时标记为签名漂移。非别名的同版本签名仍保留 drift 告警。

### 2. hybrid 样本外配对评测

从工单的 `research.hybrid` 读取同场 hybrid 与 market 概率，只统计两者齐全且有 90 分钟赛果的场次。输出 Brier、logloss、paired delta、逐场明细和 bootstrap 置信区间。无独立 hybrid 概率、市场派生概率或时间身份缺失的记录不进入分母。

### 3. 盘口移动研究侧车

新增一个只读特征提取器，从 `odds/production_movement.jsonl` 按 `match_id` 与赛前截止时间选取最早及最后安全快照，输出方向级去水概率变化、样本年龄、覆盖状态和排除理由。结果仅写入 `research.odds_movement`，不作为 hybrid 概率输入。

### 4. 强度训练质量门槛

训练产物必须声明收敛状态、参数有限性和训练策略。非收敛或参数非法模型不可标记 `production`，输出 `not_eligible`。半衰期与 rho 默认保留当前值；每联赛覆盖需来自一个带 OOS 证据的显式策略配置，不能由单次回测自动推广。

### 5. 国际赔率分时快照

新增捕获编排器，根据当前比赛的开球时间记录 T-24h、T-6h、T-75m 三类快照标签；无法取得 API key、无赛事映射或错过窗口均写结构化状态。它只能调用现有 `odds-intl` 适配器，密钥只从环境读取。计划任务配置独立交付，默认不创建系统级任务。

### 6. 强制上线门禁

新增只读 admission 报告：只有同场、独立、样本外 hybrid 在预设最小样本上同时优于市场的 Brier 和 logloss，且两项 bootstrap 区间上界均小于零，状态才为 `ELIGIBLE_FOR_HUMAN_REVIEW`。该状态不是上线许可；生产路由与推荐开关保持不变。

## 验证

- 每项行为均先新增失败测试，再实现最小代码。
- 运行 football-quant-fusion 全套测试、project021 相关训练测试，以及版本审计与发布锁核验。
- 最终报告分别列出：生产概率是否变化、研究样本量、排除原因、门禁结果和仍需等待赛果的项目。
