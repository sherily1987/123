# 足球技能工作区整合实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将足球量化融合技能的权威源码、核心依赖、LLM 对比轨与共享数据迁入 F 盘，并保持 Codex 可发现、预测和回测可用。

**Architecture:** `project018_技能工作区整合` 是唯一可写事实源；C 盘仅保留指向 F 盘的 Junction 和可再生缓存。迁移工具先生成 SHA-256 清单，再复制与核验；路径配置由统一模块读取，历史工件不重写。

**Tech Stack:** Python 3.12、PowerShell Junction、pytest、Codex 个人插件 manifest。

## Global Constraints

- 不读取或写入 API key、token、密码。
- 不删除源目录；先复制和验证，源目录只会在最终阶段改名为日期备份。
- 历史预测、赛果和回测 JSON 必须字节保留。
- 所有新文件写入 `project018_技能工作区整合`。
- C 盘的 `football-quant-fusion` Junction 是发现入口，不得承载业务文件。
