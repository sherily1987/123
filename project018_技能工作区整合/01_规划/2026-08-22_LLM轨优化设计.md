# LLM 轨优化设计

## 目标

把当前 Kimi K3 单模型轨固化为可审计的研究轨，补齐证据完整性、统一比赛登记和赛后分市场评测；在完成样本外校准前，不开放生产推荐、EV 或凯利。

## 已确认边界

- 默认模型只保留 `moonshot/kimi-k3`。
- 单模型输出必须标记 `research_only=true`、`action=observe`，不得伪装成投票共识。
- LLM 置信度不是概率，不进入 EV 或凯利计算。
- 体彩赔率仍是生产市场输入；国际赔率只作研究对照。
- 90 分钟赛果与加时/点球结果分离。
- 所有记录使用 `sporttery-<体彩ID>` 作为主键。

## 方案

### 阶段一：K3 研究轨契约

增加纯函数契约校验，确保每条预测包含比赛 ID、模型 ID、预测时间、版本、决策状态、证据状态和研究标记；错误记录拒绝进入 LLM 评测队列。

### 阶段二：证据完整性

把最近 5 场、CRS、TTG、HAFU、伤停、首发和 T-75 刷新结果统一成机器可读状态。缺失项写 `UNAVAILABLE` 和 reason code，不由模型补猜。证据清单随预测保存。

### 阶段三：结算与校准入口

新增 LLM 轨独立评测入口，按比赛 ID 去重，只接收已核验的 90 分钟赛果，分别统计 1X2、平局、比分、TTG、HAFU，并输出样本量、市场对照和校准状态。评测结果不改变生产概率。

## 验收标准

1. 单 K3 输出不能出现 `consensus`、投票强度或下注建议。
2. 证据缺口可被程序发现并保留 reason code。
3. 同一比赛只能通过统一 `match_id` 关联预测、证据和赛果。
4. 未验证 90 分钟赛果不得进入评测分母。
5. 当前 172 项 LLM 测试及融合技能测试全部通过。
6. `production_recommendations_enabled` 保持 `false`。
