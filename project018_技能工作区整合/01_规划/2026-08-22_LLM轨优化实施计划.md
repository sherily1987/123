# LLM 轨优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 固化 K3 研究轨契约，补齐证据完整性审计和可复现的90分钟分市场评测入口。

**Architecture:** 新增两个无副作用的纯 Python 模块：一个负责 LLM 记录/证据契约，一个负责结算评测；现有 `predict.py` 和 `mcp_evidence.py` 只在边界处调用它们，不改变量化生产概率。所有输出继续写入现有 `data/` 或统一工单目录。

**Tech Stack:** Python 3、pytest、JSON/JSONL、现有 `football-llm-predictor` 运行时。

**Spec:** `project018_技能工作区整合/01_规划/2026-08-22_LLM轨优化设计.md`

## Global Constraints

- 默认模型保持 `moonshot/kimi-k3`。
- 单模型输出保持 `research_only=true`、`action=observe`。
- LLM 置信度不得作为概率、EV 或凯利输入。
- 90 分钟赛果未验证时不得进入评测分母。
- `production_recommendations_enabled` 保持 `false`。
- 不把国际赔率写入生产概率或推荐门控。
