# 签名漂移与赛前双方向治理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改写历史预测和不改变生产概率的前提下，为签名漂移建立全字段重放、证明和精确别名，并让所有新预测在赛前登记可审计的单/双方向政策及独立结算指标。

**Architecture:** 扩展现有重放链生成按 `model_version + probability_signature + route` 分组的不可变证明，再由独立审批器验证证明哈希并写入精确别名；回测仅加载通过发布锁验证的别名。方向政策由独立模块根据同一赛前概率和版本化阈值生成，随预测快照登记，结算与Top1命中完全分栏。

**Tech Stack:** Python 3、JSON/JSONL、pytest、现有 football-quant-fusion CLI 与发布锁治理。

**Spec:** `project018_技能工作区整合/01_规划/2026-08-26_签名漂移与赛前双方向治理设计.md`

## Global Constraints

- 不改写任何历史预测文件、原 `model_version`、原 `probability_signature`、`prediction_as_of` 或登记时间。
- 别名键固定为 `model_version + probability_signature + route`；只覆盖证明中实际重放的路由和字段。
- 正式比较字段固定为 `final_1x2_pct`、`model_1x2_pct`、`score_matrix`、`top_scores`、`ou_2_5`、`ou_3_5`、`btts`、`hafu_model`、`ttg_score_consistency`。
- 组内任一记录变化、不可重放或时间审计失败，整组不得建立别名。
- 双方向只能随赛前快照登记；历史缺失字段不得赛后回填后计分。
- `production_recommendations_enabled=false` 保持不变；不修改概率文件、模型权重、校准参数或娱乐预算。
- LLM投票、娱乐策略和方向集合覆盖命中不得进入EV、Kelly、模型概率或正式Top1校准分母。
- 所有正式测试使用注入时钟或相对时间，不使用会自然过期的固定近期日期。
